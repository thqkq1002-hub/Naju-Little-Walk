# 나주 안내 캐릭터 제작 초안

배돌이·버들낭자·홍돌이·일반 선생님 4종. Meshy T2 형태 생성 후 Blender에서 채색했다. 원본 GLB와 v4 편집본을 함께 보존한다. `generation-reference.png`는 원본 매뉴얼을 참고해 AI로 정리한 이미지이며, 선생님은 신규 디자인이다.

기술 검사와 GLB 재불러오기를 통과한 초안이며 조형 보정·리깅·앱 배치는 아직 남아 있다. 홍돌이의 몸통과 분리된 장갑, 정면 색상 투영의 경계도 보정해야 한다.

앱의 public 폴더에는 넣지 않았으므로 산책 화면에 자동으로 나타나지 않는다. Blender 편집용 파일과 제작 참조 자료로 보관한다. 자세한 비용과 검증은 `knowledge/naju-npc-meshy-production-2026-10-02.md` 참조. 다운로드용 서명 URL 및 API 키는 포함하지 않는다.
