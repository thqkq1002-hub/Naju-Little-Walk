# 다시초 고도화 v80 — 배치를 유지한 재질·표현 개선

작업 기준: 2026-10-03. **현재 만들어진 학교의 건물 형태와 배치, 운동장·정문·길·실내 동선은 유지**한다. 사용자는 최근 리모델링 사실과 오래된 자료의 한계를 지적한 뒤, 기존 모델을 그대로 고도화하도록 요청했다. 이번 작업을 리모델링 이후 실측 복원으로 설명하지 않는다.

2021년 정문 사진과 2022년 위성영상은 기존 모델이 어떻게 만들어졌는지 설명하는 **과거 자료**로만 남긴다. 공사 완료 시기와 범위가 확정되지 않았으므로 최근 사진도 자동으로 ‘공사 이후’라고 단정하지 않는다. 2022년 역사관 기사 또한 현재 실내 형태의 근거에서 제외한다.

## 제작 범위

- Blender의 기존 `outputs/palette-v51/dasi-neighborhood-color-v51.blend`를 읽어 별도 `outputs/dasi-v80/dasi-neighborhood-detail-v80.blend`로 저장한다. 원본 SHA-256이 그대로인지 검증한다.
- 벽돌 줄눈·표면 요철, 석재 입자, 보도 이음매, 나무결, 잔디와 포장재의 거칠기를 원본 절차적 텍스처로 제작한다. 학교 사진이나 학생 얼굴을 텍스처로 배포하지 않는다.
- 나무의 기존 수관 범위 안에서 잎의 실루엣과 가지를 보강한다. 담쟁이는 기존 위치 안에서 잎 형태를 세분화한다. 수목의 수종과 각 잎의 실제 위치를 실측한 것이 아니다.
- 기존 창문과 배수관 범위 안에 작은 물끊기·고정구를 넣는다. 방·건물·문·경계·놀이터를 새로 만들거나 재배치하지 않는다.
- 도로·농지와 가는 부품의 그림자 처리를 수정하고, 넓은 장면의 겹치는 얇은 표면에 깊이 정밀도를 적용한다.
- 웹용 GLB는 재질·공간별로 묶어 호출 수를 줄이고, 외부 이미지 요청 없이 압축 파일 하나로 전송한다. Blender 편집본은 묶기 전 개별 물체를 유지한다.
- 전체 주변 지도에 더해 본관·정문·운동장·별동을 확인하는 카메라 버튼을 제공한다. 이 버튼은 배치나 산책 위치를 바꾸지 않는다.

## 확인과 미확인

`public/dasi-neighborhood-world.json`과 `public/dasi-world.json`의 건물·벽·문·바닥·충돌·시작 위치·실내 경로 데이터는 그대로 유지하고, 고도화 메타데이터를 추가한다. 기존 체험 교실·도서실은 실제 실내 복제가 아니라 가상 구성이라는 안내를 유지한다.

실제 리모델링의 공사 범위, 최신 놀이터 기구, 개별 건물의 정확한 치수와 높이는 이번 자료로 확인하지 못했다. © OpenStreetMap 기여자 및 ODbL 출처 표시를 유지한다. 기존 배치의 출처와 한계는 [기존 다시초 자료](sources/DASI_REFERENCES.md)에 보존한다.

- Git의 작업 이전 데이터와 두 지도 JSON의 건물·충돌·문·바닥·시작 위치·실내 경로·주변 구획·간판 정보를 직접 비교했고 모두 일치했다. [독립 검증 기록](sources/dasi-v80-verification.json).
- 산책·충돌 검사 73개, 태블릿 입력·조명·렌더링 제어 검사 8개 통과. 추가 재질·압축·내장 이미지·수목 거리 전환·데이터 보존 검사 9개 통과. 총 90개.
- TypeScript 검사 및 Vite 운영 빌드 통과. 기존 큰 청크 안내는 남아 있다.
- 기존 편집본의 메시 9,711개를 웹용 645개로 구성했다. 원본 편집 객체는 별도 `.blend`에 남긴다.
- 세부 잎 카드 57,808개, 담쟁이 카드 2,800개. 근거리 11개 구역과 원거리 수관 11개 구역을 전환한다. 원거리 수관의 범위가 기존 수관 위치와 일치하는지도 검사했다. 실제 수목·잎 수를 뜻하지 않는다.

- 브라우저에서 주변 전경·본관 정면·산책 시작 지점을 확인했다. 1024×600 화면에서 버튼과 안내 패널이 겹치지 않았고 콘솔 오류·경고가 없었다. 실제 Android 기기의 성능 측정은 아니다. 화면 기록: `outputs/dasi-v80/tablet-front-v80.png`.
- 원래 작은 학교만의 `dasi-elementary.glb`는 보존했다. 운영 학교 화면은 고도화한 `dasi-neighborhood.glb.gz`를 사용한다.
