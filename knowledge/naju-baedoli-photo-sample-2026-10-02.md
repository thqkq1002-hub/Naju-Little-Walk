# 배돌이 Meshy 사진 기반 비교 샘플

2026-10-02. 사용자의 “메쉬의 사진기반형성으로 하나 만들어 주세요 그냥 그리고 크레딧 한번 봅시다” 요청을 실행했다.

## 실행 경로

힉스필드 MCP 모델 목록에는 Meshy 사진→3D가 있지만 현재 연결에 3D 작업 제출·견적 도구가 노출되지 않았다. 힉스필드 웹 화면도 로그인되지 않은 상태였다. 기존에 연결돼 있는 Meshy API 계정은 유효했고 잔액은 11크레딧이었다.

현재 잔액으로 생성 가능한 Meshy T2 형태 생성 5크레딧 옵션을 사용한다고 알린 뒤 한 번만 제출했다. 채색 포함 옵션은 최소 15크레딧으로 현재 잔액을 초과해 실행하지 않았다. 따라서 이 결과는 상위 Meshy 7.1 모델의 품질 비교 결과가 아니다. 힉스필드 크레딧을 Meshy API 크레딧으로 환산하거나 사용하지 않았다. Windows에서 차단된 힉스필드 CLI는 재실행하거나 우회하지 않았다.

## 산출물과 검증

`assets/npc/meshy-photo-sample-20261002/`에 생성 원본 GLB·Blender 편집본·정규화 GLB·정면/사선/뒷면 렌더·작업 기록을 저장했다. `scripts/meshy_baedoli_photo_sample.py`는 한 건 제출과 상태 복구·다운로드를 담당하고, `scripts/render_baedoli_photo_sample.py`는 원본을 보존한 채 Blender에서 검토본을 만든다. API 키는 기존 환경변수에서 사용하고 파일이나 로그로 출력하지 않았다. 서명된 다운로드 주소는 Git에서 제외되는 `outputs/`에만 보관한다.

GLB 헤더·버전·전체 바이트 길이·내장 버퍼를 검증했다. 생성 원본은 메시 1개·삼각형 15,779개·286,768바이트다. Blender 재내보내기에서 퇴화 삼각형 1개가 제외돼 검토본은 15,778개·289,300바이트이며 높이 1.2m로 맞췄다. 텍스처와 애니메이션은 없다.

세 시점 실제 렌더를 직접 확인했다. 엄지, 손바닥, 팔, 모자와 목수건이 참조 실루엣을 따라 입체화됐다. 다만 엄지 외 손가락은 일부 뭉쳤고, 모자 짜임·얼굴의 색상 세부는 없다. 단일 정면 이미지에서 보이지 않는 뒤쪽은 AI 추정이다. 이는 검토용 형태 샘플이며 채색·리깅 완성이나 최고 품질을 의미하지 않는다.

기존 3D Jutsu 배돌이와 기존 운영 캐릭터·사용자 Blender 수정본은 보존했다. 이번 요청에서 앱 배치·기존 삭제·GitHub 푸시·Vercel 배포는 실행하지 않았다.
