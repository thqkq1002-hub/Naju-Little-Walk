# 전망실 첫 화면 수정

- 증상: `?place=bitgaram-observatory`를 직접 열거나 지도·푯말에서 입장하면 공통 전체 보기로 시작했다. 실내에서 바라보도록 만든 파노라마를 외부 위쪽에서 관찰해 바닥 원판과 늘어난 사진 영역이 노출됐다.
- 원인: 기존 자동 걷기 시작은 유효한 `at` 도착점이 있는 주소에만 적용됐다. 일반 전망실 주소는 조감도 상태로 남았다.
- 수정: 전망실 월드에 `viewMode: panorama`를 지정하고, 일반 주소와 입구 전환 모두 기존 내부 시작점·눈높이에서 걷기로 연다.
- 전망실에서는 전체 보기 버튼을 제외했다. 내부 파노라마에서 외부 조감도를 선택하지 않도록 엔진에도 같은 제한을 적용했다. 공원과 다른 맵의 전체 보기는 유지한다.
- 일시정지, 이어 걷기, 드래그 시선 이동, 외부 복귀와 지도 선택은 기존 기능을 사용한다. 세로 태블릿에서는 이동을 시작하지 않고 회전 안내를 유지한다.
- Blender 모델·파노라마·충돌 형상은 변경하지 않았다. 새로운 실제 지도 자료나 추정 시설도 추가하지 않았다.
