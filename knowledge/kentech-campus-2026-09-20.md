# KENTECH 캠퍼스 보강

## 문제와 수정

기존 맵은 2022년 최초 강의동의 OSM 윤곽 하나만 사용했다. 상층 외벽과 지붕에 `hide_in_overview`가 붙어 전체 보기에서 수직 프레임만 남았다. 이번 장면은 별도의 Blender 수정본으로 제작하며 상층과 지붕을 전체 보기와 걷기 모두에서 유지한다.

원본 사진과 위성영상은 참고용 `work/kentech-v52`에 보관하며 사이트에 재배포하지 않는다.

## 실제 자료와 추정

실제 위치 기반: OSM의 강의동 I·II, 연구·지원동, RC, 체육 공용동, 운동장·코트, 주차장, 도로의 윤곽과 상대 배치.

사진 기반: 흰 수평 띠, 청록·회청색 창, 상층 세로 핀, 아트리움, 출입구 캐노피, 태양광, RC의 벽돌색과 두 긴 동, 앞마당의 대각 산책로.

추정: 모든 높이·층고·창 간격, 가구·조명·식재 개체 위치, 주차 차량, 길 폭. 도서관은 공사 사진의 원형 외곽에 추정 마감을 적용했다. 1층은 공개 평면을 확보하지 못해 간소한 관람 동선이며 강의실·연구실·생활관 내부는 재현하지 않는다. 측량 모델 또는 완전한 실사 복원으로 표시하지 않는다.

## 제작과 성능

`scripts/build_kentech_campus.py` → `outputs/kentech/kentech-campus-v52.blend` → `scripts/finish_kentech_campus.py` → `kentech-campus-v52-final.blend` → `public/models/bitgaram-kentech.glb(.gz)`. 최종 수정본만 다시 내보내고 렌더하려면 `scripts/render_kentech_campus.py`를 사용한다.

기존 `.blend`는 보존한다. 새 Blender 원본에는 부품별 편집 가능한 메시를 남기고, 내보내기 단계에서 같은 불투명 재질의 장식 부품을 합친다. 바닥의 그림자 투영을 끄고 기존 캠퍼스 최적화 경로를 적용했다. 지면·벽·가구·도서관·생활관의 충돌은 `public/bitgaram-kentech-world.json`에 함께 갱신한다.

## 검증

- 주요 건물·시설 윤곽 12개, 조경 수목 117그루. 편집용 장면의 11,652개 물체를 내보내기 시 약 100개 메시로 합쳤다. GLB 약 8MB.
- 기존 이동 검사 73개 통과. 신규 캠퍼스 검사 3개는 두 출입구, 앞마당·생활관 접근, 닫힌 벽 충돌, 상층 표시 유지와 gzip 동일성을 검증한다.
- 앞마당 가로등 5개를 보행로 중앙에서 가장자리로 옮겨 연속 이동 검사를 통과했다.
- TypeScript 검사와 Vite 정적 빌드 통과. Blender 조감·정면·1층 렌더를 직접 확인했다.
- 브라우저에서 로딩 완료, 산책 전환, 장소 지도 및 1층 도착 좌표를 확인했고 콘솔 오류는 없었다. 브라우저 화면 캡처는 도구에서 실패해 시각 확인은 Blender 렌더를 사용했다. 실제 FPS는 측정하지 않았다.

## 후속 디테일 보강 — v53

동일한 공식 항공사진과 2026년 서울신문 정면 사진을 다시 비교했다. 기존 모델의 보행로를 차도로 표현한 부분과 앞마당의 중복 길을 먼저 정리했다. 강의동 위치와 1층 개방 범위는 유지한다.

- 외벽: 창마다 회청·청록색을 약하게 달리하고, 층 사이 불투명 유리 띠·작은 개폐창·돌출 차양을 추가했다. 최상층의 흰 수직 차양은 원통형 얇은 선에서 깊이가 있는 판으로 바꿨다. 서쪽 짙은 아트리움이 최상층까지 올라가던 표현도 사진에 맞춰 낮췄다.
- 출입구: 상자형 캐노피 테두리·천장 보·열린 문틀·손잡이·매트·화분을 구성했다. 5m 출입 폭은 유지하며 화분 충돌은 장소 JSON에 기록한다.
- 앞마당: 밝은 석재 포장, 석재 간 이음, 선형 배수구, 대각 보행로와 잔디 경계로 구성했다. OSM `footway`에 잘못 적용된 아스팔트 재질을 제거했다.
- 수목·생활관: 어린 나무 수관을 불규칙한 잎 무리로 다듬고 앞마당 수목의 흙자리·테두리를 추가했다. 생활관 창에는 세로 분할대와 벽돌색 돌출 기둥을 더했다.

사진으로 확인한 형태와 재질 구분을 따른다. 창·차양·포장의 정확한 치수, 조경 개체·화분·문 손잡이·배수구 위치는 추정이며 실측 재현으로 간주하지 않는다. 새 사진을 텍스처로 재배포하지 않는다.

`scripts/detail_kentech_campus.py`가 보존된 `kentech-campus-v52-final.blend`를 읽어 **새 파일** `outputs/kentech/kentech-campus-v53.blend`를 만든다. 기존 편집본을 덮어쓰지 않는다. 같은 재질을 묶어 내보내며 용량·메시 수는 `sources/kentech-v52/detail-v53-metrics.json`에 기록한다.

최종 검토에서 `scripts/finish_kentech_detail.py`로 간판 가림, 연결동 유리 분할, 수관의 불필요한 면을 다듬고 `kentech-campus-v53-final.blend`로 보존했다. 18,952개 편집 물체를 112개 내보내기 메시로 묶었다. GLB 14.75MB, gzip 3.82MB로, 첫 디테일본의 gzip 6.10MB 대비 약 37% 감소했다. 실제 FPS 향상을 측정한 것은 아니다.

이동·충돌 검사 76개를 통과했고, 최종 메시 수정 후 캠퍼스 전용 검사 3개도 다시 통과했다. TypeScript 검사 통과. 조감·정면·출입구 Blender 렌더를 비교해 보행로 중복과 출입구 간판 가림을 확인·수정했다.

최종 Vite 빌드가 성공했다. 로컬 브라우저에서 새 모델의 로딩, 산책 모드 전환과 정문 화면을 직접 확인했으며 콘솔 오류는 없었다. 이번에는 브라우저 화면 캡처도 성공해 출입구·간판·유리·포장을 확인했다.
