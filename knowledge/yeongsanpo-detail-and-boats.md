# 영산포 상세 보완과 황포돛배 조종

2026-09-08 작업. Blender에서 모델링하고 GLB로 내보낸 뒤 Three.js에서 승선·보행·조종을 연결한다.

- [KBS광주 2022-08-19 방송 영상](https://www.youtube.com/watch?v=QmWY0WxyYcY): 실제 프레임의 약 75–100초 갤러리, 205–310초 승선·선박 외관과 좌석을 참조했다. 원본 영상과 추출 이미지는 배포하지 않는다.
- 역사갤러리의 검은 철망 천장, 청회색 연표판의 **상단 3개·하단 4개** 입체 사진상자, 큰 사각 돛 스크린과 목선, 연속 유리 음식장 3칸, 볏짚 묶음을 올린 옹기를 사진과 대조했다. ## 추정하거나 탐험을 위해 조정한 부분

- **나주호 21.0 × 5.6m는 사진 비례 추정**이다. 공개 실측 제원을 확인하지 못했다. 작은 빛가람호나 목포의 다른 황포돛배 치수를 혼용하지 않았다.
- 두 선박의 흘수·수면 위 갑판 높이 1.1m·객실 치수·난간 높이·조타 장비 배치는 사진 참고 추정이다. 영상에 없는 실내 전체를 확인한 것으로 주장하지 않는다.
- 왕건호 돛을 펼친 모습은 공식 사진을 참고했다. 현재 운항 때마다 같은 돛 상태인 것은 아니다.
- 승선 입구와 객실 문은 키보드·터치 보행을 위해 넓이를 확보했다. 승선과 운전석 이동은 버튼으로 지정 지점까지 이동한다. 선박의 동력 조종은 체험용이며 실제 선박 시뮬레이터가 아니다.
- 조종 범위는 현재 모델의 강 구역 안이다. 강가, 선착장, 다른 배, 낮은 교량 구간에 닿기 전에 정지한다. 한강·영산강 전체로 이어지는 항로가 아니다.
- 갤러리의 벽면 사진과 긴 본문은 원본을 복제하지 않고 **직접 만든 흑백 포구 부조와 짧은 설명**으로 해석했다. 따라서 전시 원문·사진까지 완전히 동일하지 않다.
- 계단 아래 빈 지반과 문학관 천장 틈을 닫는 구조는 기존 사진의 연결 형태를 기준으로 보완한 것이며 실측 구조 설계가 아니다.

## 탐험 동작

1. 영산포에서 배 이름의 선착장 버튼 또는 지도의 승선 입구를 선택한다.
2. 입구에서 승선 버튼이나 **F**로 배에 오른다. **WASD**로 갑판·객실을 걷는다.
3. **운전석으로 / F**를 누르면 출항 보조로 배를 천천히 선착장에서 띄운다. 이후 **W/S** 전진·후진, **A/D** 방향, **Space** 제동. 키를 놓으면 감속한다. 출항 보조는 긴 선체가 정박 시설에 걸리지 않도록 넣은 체험 편의 동작이다.
4. **갑판 둘러보기**는 배를 정지시킨 뒤 선내 보행으로 돌아온다. 메뉴·지도·화면 전환도 즉시 정지한다.
5. **선착장으로 복귀**는 원래 계류 위치로 되돌리는 체험 편의 기능이다. 정박했을 때만 내릴 수 있다. 지도 이동 중에는 탑승한 배를 계류 위치로 돌려놓는다.

## 파일과 검증

- 원본 v0.3 Blender 파일은 보존하고 `outputs/yeongsanpo*-detail.blend`, `outputs/najuho-detail.blend`, `outputs/wanggeonho-detail.blend`를 별도로 만든다.
- 선박은 개별 GLB 및 로컬 좌표의 충돌·바닥 정보로 관리한다. 고정 도시 메시와 합치지 않는다.
- 기존 보행 경로 회귀, 두 배 승선 위치·조타실·후미 왕복, 강 경계·선박 충돌·제동, GLB 천장의 위쪽 광선 교차를 검증한다.
- 배포에는 웹 모델과 JSON만 포함하며 Blender 실행 파일, 참고 사진·영상, 임시 자료, `.blend`는 포함하지 않는다. `.blend`는 별도의 GitHub Release 산출물로 제공한다.
