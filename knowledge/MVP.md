# 금성관 탐험 MVP

## 확정한 방향

- 사용자는 가상 골목보다 실제 나주 한 구역을 선택했다.
- 대상 구역은 금성관 주변으로 설정했다.
- 제작은 Blender, 체험은 Three.js가 담당한다.
- 지도 이미지에서 외관을 추측하는 방식이 아니라 공개 지도 좌표를 사용한다.

## 데이터와 추정

| 요소 | 처리 |
|---|---|
| 건물 5채의 위치·바닥 윤곽 | 원본 OSM 노드 좌표 사용 |
| 도로·구역 경계 | 원본 OSM 선·면 사용 |
| 금성관 지붕·기둥·창호·마루 | 공식 사진에서 확인한 특징으로 제작, 치수는 추정 |
| 박석길·나무 | 사진 방향·규모 참고, 배치는 추정 |
| 문 위치·실내 전시 | 탐험 검증용 가상 구성 |
| 도로 폭 | 유형에 따른 기본값 |
| 주변 미등록 건물 | 생성하지 않음 |
| 지형 | 평면 |

기준 좌표는 위도 35.0327357, 경도 126.7167886입니다. WebGL 좌표는 동쪽 +X, 위 +Y, 남쪽 +Z이고 Blender 좌표는 `(X, -Z, Y)`로 변환합니다.

## 다음 단계

1. 사용자가 MVP의 이동감과 탐험 범위를 확인한다.
2. 실제 항공사진·추가 건물 윤곽 자료를 확보해 미등록 건물을 보완한다.
3. 공식 사진 기반 외관을 실측 자료로 보완하고 출입구·담장·외삼문·중삼문을 더 정교하게 수정한다.
4. 자료 확보 여부에 따라 실제 내부 재현 여부를 별도로 결정한다.

## 검증의 범위

자동 검증은 이동·벽 충돌·실내 진입과 복귀·경계·Blender GLB 구조를 다룹니다. Blender 조감도를 렌더링했습니다. 브라우저 직접 조작 검사는 이번 요청에서 별도로 요청되지 않아 수행하지 않았습니다.

선택적 WebMCP 도구는 상태 조회와 보기 전환을 제공합니다. 지원되는 브라우저 검증 컨텍스트에서의 호출 검사는 수행하지 않았으며, WebMCP 미지원 브라우저에서도 일반 조작은 동작하도록 구성했습니다.
