## 추정 및 창작 부분

- 기와의 개별 폭·겹침과 장식, 단청의 새 꽃 띠는 사진에서 관찰한 형태를 참고한 원래 제작물이다. 실제 문양의 완전 복제나 실측으로 표시하지 않는다.
- `assets/geumseonggwan-v76/materials`의 목재·돌·흙·기와·잔디 질감은 절차적으로 제작한 새 이미지다. 현장 사진을 복사한 텍스처가 아니다.
- 잎·가지·여름 수관은 추정이다. 사진의 겨울 수목과 구분한다.
- 원본 `outputs/palette-v51/geumseonggwan-color-v51.blend`를 수정하지 않았다. 편집본은 `outputs/geumseonggwan-exclusive-v76/geumseonggwan-exclusive-v76.blend`다.
- 앱은 경내만 제공한다. 기존 주차장·시가지 참고 좌표는 과거 제작 자료이며, 운영 장면과 경내 이동 지도에서는 제외했다.

파일 용량과 표시 객체 수는 `metrics.json`에서 확인한다. 구조·이동·gzip 복원과 원래 목재 색 유지 여부를 자동 검사하고, 정면·전체·기와 근접·실내를 별도로 렌더링해 검토한다.
