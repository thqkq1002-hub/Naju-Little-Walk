# 수목원 사진 대조와 수형 수정

## 대조한 근거

- [나주시 공식 소개](https://www.naju.go.kr/tour/food/accommodation/others?idx=292&mode=view): 메타세쿼이아길·향나무길의 존재를 확인했다.
- [2021년 현장 방문 사진](https://hangamja.tistory.com/1607): 보관 중인 향나무길 사진(92), 장미원 사진(89)을 다시 직접 열었다. 향나무는 바닥 가까이까지 잎이 차는 긴 원뿔형과 둥근 타원형이다. 장미원은 낮은 울타리, 자갈길, 원뿔 지지대, 꽃보다 훨씬 무성한 관목 잎이 특징이다.
- [현장 여행 기사](https://v.daum.net/v/WW9GV4at7I): 둥글게 다듬은 향나무, 연필향나무와 에메랄드그린의 열식이라는 설명으로 수형 차이를 교차 확인했다.
- 기존 메타세쿼이아길 사진 `work/arboretum-path.jpg`: 높은 줄기 아래 보행 공간과 머리 위로 연결되는 수관, 길 가장자리의 낮은 식재를 비교했다.

## 변경 이유

이전 버전은 개별 잎 디테일을 늘리는 과정에서 향나무까지 줄기가 드러나는 일반 수형으로 바뀌었고, 숲과 장미원 내부가 지나치게 비어 보였다. 단순한 잎 수 증가보다 수종별 전체 윤곽과 잎이 차지하는 부피를 우선 수정한다.

- 향나무: 긴 원뿔형·타원형의 조밀한 상록 수형. 기존 줄기 위치 유지.
- 일반 수목: 작은 불규칙 수관이 겹치고 가장자리에 개별 잎이 보이는 구조.
- 메타세쿼이아: 높은 줄기와 계층별 가지, 상부 수관의 연속성 보강.
- 장미원: 갈라진 가지와 잎이 있는 관목, 분홍·크림·붉은색·살구색 꽃을 혼합.
- 숲 바닥: 기존 줄기 주변 낮은 초본만 보강. 보행로·시설 배치와 충돌 부피 유지.

## 추정과 한계

정밀 실측이나 최신 현장 촬영을 수행한 것은 아니다. 이전 지도·위성 기반 위치를 유지하되 개별 수종, 수량, 크기, 장미 품종과 개화 시기, 식재 위치는 추정이다. 사진과 동일한 현재 상태를 보장하지 않는다. 원본 사진은 배포하지 않고 Blender에서 새로 만든 형상과 자체 재질만 내보낸다.

## 성능과 검증

기존 거리별 정밀도와 식물 인스턴싱을 유지한다. 가까운 모델·먼 모델의 쌍, 압축 일치, 경로·충돌 회귀를 검사하며 실제 브라우저 FPS는 측정하지 않는다. 수치는 `sources/arboretum/reference-finish-metrics.json`에 기록한다.
