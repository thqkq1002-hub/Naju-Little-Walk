# 나주 산책 공유 미리보기

- 적용 주소: https://najuwalk.mumuworld.com/
- 이미지: `public/og/naju-walk-share-v1.jpg` (1200 × 630, JPEG)
- 제목: 나주 산책 | 3D로 만나는 나주
- 설명: 금성관, 영산포, 빛가람, 수목원과 느러지까지. 나주의 명소를 3D로 걸으며 만나는 온라인 산책.

## 제작 방식

현재 운영 중인 앱의 느러지 수국 언덕길을 직접 캡처하고, 기존 나침반 아이콘·녹색 계열과 한글 제목을 HTML/CSS로 배치했다. 장면을 새로 그리거나 실제 현장 사진으로 표시하지 않는다. 지도 데이터의 OpenStreetMap/ODbL 표기를 이미지에도 유지했다.

## 동작

정적 `index.html`에 OG와 Twitter 카드 메타데이터를 넣어 JavaScript를 실행하지 않는 링크 수집기도 제목·설명·이미지 URL을 읽을 수 있다. 대표 URL과 이미지 URL은 새 서브도메인을 사용한다. 이미지 이름은 버전을 포함해 다음 디자인 수정 때 새 파일명으로 갱신할 수 있다.

## 검증

- JPEG 1200 × 630, 91,853바이트와 실제 한글 배치를 확인했다.
- 정적 HTML의 메타데이터 중복·누락, 대표 URL과 이미지 URL, 원래 앱 진입 스크립트 보존을 확인했다.
- 배포 완료 기준: GitHub 커밋의 Vercel 운영 배포가 준비되고, 새 주소의 HTML과 이미지가 익명 수집기 요청에 HTTP 200으로 응답해야 한다.

지형, 이동 기능, 3D 모델은 이번 변경 대상에 포함하지 않았다.

규격 참고: [Open Graph protocol](https://ogp.me/).
