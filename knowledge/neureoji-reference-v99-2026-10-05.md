# 느러지 전망대·수국길 레퍼런스 보완 v99

2026-10-05 사용자 요청에 따라 v96–v98 수정본을 운영 브랜치에 push하고 GitHub PR #1로 main에 병합했다. Vercel production 배포 `dpl_AE2ZoNtFkGNkzSSPzQYLMo4E9kDV`가 READY이며 운영 도메인에서 v98 장소 JSON과 gzip 모델 SHA-256이 일치함을 확인했다. 증거는 `sources/neureoji-polish-v98/deployment.json`에 있다.

그 뒤 [2026-07-10 현장 사진 기사](https://localm.kr/bbs/board.php?bo_table=news&me_id=4&wr_id=4488)의 사진 4장과 [2024-07-08 방문 사진](https://forme13.tistory.com/3621)을 대조했다. 사진에서 흰색 도장 철골, 원형 지붕, 갈색 전망대 난간, 수국의 푸른색·보라색·분홍색 군집, 길의 미세한 입자감을 참고했다. 보행로의 정확한 폭·개별 식재·가지·꽃·포장 입자 크기를 사진으로 실측했다는 뜻은 아니다. 기사 사진은 `work/`에서만 검토하며 배포에는 사용하지 않았다.

v98 Blender 원본을 보존하고 `outputs/neureoji-v99/neureoji-reference-v99.blend`에 새 편집본을 저장했다.

- 평평하던 lacecap 중심부 1,596개를 얕은 곡면으로 다듬었다. 꽃송이를 새로 배치하거나 경로 안으로 옮기지 않았다.
- 수국 잎 3종의 색을 조정하고 매트한 재질을 적용했다. 블렌더 노드와 GLB baseColorFactor에 같은 해석을 반영했다.
- 두 수국길 바닥에 자체 제작한 미세 포장 입자 텍스처와 일관된 평면 UV를 적용했다. 지형 높이와 바닥 삼각형은 그대로다.
- 전망대 도장 철골을 더 매트하게 조정했다. 기존 원형 지붕·난간·계단·표지 글자·치수는 유지했다.
- 원경 수관 텍스처를 256px로 정리했다. 가까운 숲의 입체 수관과 가지는 유지했다. gzip 전송량은 16,703,143바이트로 v98보다 66,845바이트 작다.

고도는 v98 재검토 결론을 따른다. 지면 모델 y=45.76368m, 상층 데크 y=57.76368m, 구조 전체 높이 15.35m다. DEM 표면과 지면 실측을 구분하며 수면 평면은 관측 수위가 아니다. 추정·가상 요소를 새 지도 사실로 승격하지 않았다.

공통 이동 74개, 느러지·식생·표고 관련 15개 테스트 및 production 빌드가 통과했다. 보행 바닥 재질 통합으로 glTF primitive 배열은 달라졌지만 두 길의 모든 삼각형 좌표가 정확히 같음을 확인했다. 나머지 보호 지형·강·바닥·시설 POSITION 스트림과 원본 v98 Blender 해시도 검증했다(총 41개 보호 메시). 충돌 solids는 기존 검토 스냅샷과 같다. 브라우저에서 숲길 도착과 새 모델 URL 로딩을 확인했고 JS 오류가 없다.

v99도 같은 운영 브랜치에 반영하고 main에 병합한다. 기존 웹 배포 설정과 OSM·ODbL 안내를 유지한다. 새 수정본들의 Blender 파일은 배포 폴더에서 제외하며 GitHub Release `observatory-refinement-v99-20261005`의 보존 압축 파일로 제공한다. 최종 배포 성공은 Vercel 상태 및 운영 모델 해시를 확인한 결과로 보고한다.
