# 금성관 전용 앱 정밀화 계획

## 확정 범위

사용자 확인: 앱 전체를 금성관 전용으로 변경한다. 다른 지역 선택과 이동을 운영 화면에서 제거한다. 기존 지역 모델과 사용자가 수정한 Blender 원본은 보존한다. 금성관 경내의 정청, 동·서 익헌, 망화루, 중문, 박석길, 담장, 비석과 수목을 포함한다. 외부 주차장·차량·상가·도로는 이번 전용 장면에 포함하지 않는다.

## 자료와 재현 원칙

- [국가유산 디지털 서비스](https://digital.khs.go.kr/heri/heriDetail.do?ctptNo=1123620370000&ctptUid=13898859673312200636): 정면 5칸·측면 4칸, 팔작지붕·겹처마, 익공, 2고주 7량, 금모로 단청의 근거. 구조 용어는 최신 공식 설명을 우선한다.
- [한국민족문화대백과사전](https://encykorea.aks.ac.kr/Article/E0011462): 정청과 동서 익헌, 정측면 사진. 2009년 사진과 현재 모습은 구분한다. 문짝 구성과 처마 형상 비교에 활용한다.
- 기존 OSM 경내 경계 및 건물 지붕 윤곽을 유지한다. ODbL 출처 표기를 유지한다.
- 치수·장식 곡선·수목 가지와 질감은 사진 비례를 토대로 만든 추정 모형이다. 실측·스캔 또는 현재 현장의 완전 복제로 표시하지 않는다.

## 구현 순서

1. **전용 화면:** 기본 진입과 기존 지역 주소를 금성관으로 통일한다. 금성관 경내 지도만 제공한다. 제목·설명·도움말·캐릭터 안내를 경내 산책에 맞춘다.
2. **장면 집중:** 기존 채색 Blender 파일을 읽고 별도 새 수정본으로 저장한다. 외부 주차장·차량·주변 건물·도로를 새 장면에서 제외한다. 경내 윤곽에 맞춰 카메라와 이동 범위를 설정한다.
3. **건축 정밀화:** 기존 지붕의 곡선을 따라 기와의 골·겹침·막새·용마루를 보강한다. 공포·처마 끝과 단청 띠를 더 읽기 쉽게 한다. 문살과 현판, 목재·초석·기단의 재질 차이를 보강한다.
4. **마당과 조경:** 박석의 돌색과 거칠기, 흙마당과 잔디의 경계를 자연스럽게 만든다. 담장 석재와 기와, 보호수 줄기·굵은 가지·수관의 차이를 보강한다. 무작정 시설을 추가하지 않는다.
5. **웹 성능:** 반복 장식은 Blender에서 재질별 묶음으로 내보낸다. 근거리에서 읽히는 디테일은 유지하면서 개별 오브젝트 수를 줄인다. GLB와 gzip 파일을 갱신하고 실제 로딩·산책을 확인한다.
6. **검증과 공개:** 변경한 경계와 지형에 맞춰 city-world.json을 갱신한다. 시작 지점과 버들낭자의 위치, 문 통과·계단·경내 지도 이동을 검사한다. 전체·정면·기와/단청 근접 결과를 확인한 후 사용자 기존 GitHub/Vercel 자동배포 흐름에 반영한다.

## 완료 기준

- 앱에서 금성관 이외의 장소를 선택하거나 진입할 수 없다.
- 전체 보기에 외부 주차장·차량·상가가 나오지 않는다.
- 정청·익헌·문루의 지붕 형태, 기와 골과 처마, 문살과 목재, 박석과 마당 재질이 구분된다.
- 경내 산책과 안내 캐릭터는 작동하고 태블릿 가로모드 UI를 유지한다.
- 지도 출처·사진 시점·추정 재현의 한계는 제작 자료에서 확인할 수 있다.
- 기존 Blender 원본과 다른 지역의 제작 자료를 보존한다.

## 진행 기록

- 계획 작성 완료. 기존 운영 금성관 모델은 약 19,827개의 개별 메시이며, 별도 채색 Blender 원본이 확인되었다. 반복 부재를 합쳐 표시 비용을 줄일 필요가 있다.
- 구현 완료: 앱 진입과 기존 지역 주소를 금성관으로 통일했다. 금성관 경내 지도만 연결하고 제목·안내·버들낭자 대화를 수정했다. 외부 건물·주차장·차량·도로를 새 모델에서 제외했다.
- 새 Blender 편집본: `outputs/geumseonggwan-exclusive-v76/geumseonggwan-exclusive-v76.blend`. 기존 채색 원본은 보존했다. 정청·동서 익헌·망화루·중문의 다섯 지붕에 개별 기와 골과 겹침을 추가했다. 목재·석재·흙·기와·잔디의 색·거칠기·노멀 이미지를 새로 제작했다. 단청 띠와 여덟 수목의 잎·수관도 보강했다.
- 반복 부재 정리: 장면 객체 19,827개 → 543개(메시 541개). 웹용 텍스처는 512px WebP, 새 Blender 원본에는 1024px 제작 질감을 보존했다. GLB 37,756,824바이트, gzip 19,949,188바이트로 25MiB 배포 파일 제한 안에 들어간다. 다운로드 용량은 이전보다 늘었으며 객체 감소를 실제 FPS 향상 수치로 해석하지 않는다.
- 충돌·바닥 갱신: OSM 경내의 비정형 경계 밖으로 지도 이동과 산책을 제한했다. 5단 계단을 통해 정청 마루에 올라가고 돌아올 수 있다. 망화루·중문 통과, 모든 경내 목적지 도착, 버들낭자 시작 위치를 검사했다.
- 검증: `tests/world.test.mjs`, `tests/geumseonggwan-exclusive.test.mjs`, `tests/npc-placement.test.mjs`의 86개 검사 통과. TypeScript 검사와 정적 빌드 통과. 전체·정면·기와 근접·실내를 Blender에서 렌더링했다. 로컬 브라우저 1280×800에서 기존 지역 링크의 금성관 전환, 경내 지도, 정청 마루 도착, 출발 지점의 버들낭자 버튼을 확인했고 브라우저 경고·오류는 없었다. 실제 안드로이드 기기에서의 OS 회전·성능 수치는 아직 측정하지 않았다.
