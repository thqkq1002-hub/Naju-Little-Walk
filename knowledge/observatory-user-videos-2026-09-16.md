# 실제 전망 영상 보기

사용자가 2026-09-16 제공한 영상 두 개를 원본 그대로 사용했다. `videoplayback (1).mp4`는 실제 실내 및 창밖 촬영, `videoplayback.mp4`는 주변 항공 영상이다. 둘 다 640×360이며 영상 프레임으로 포스터를 추출했다. 360도 파노라마로 합성하거나 원본 해상도를 높였다고 표시하지 않는다.

사용자가 선택한 방식에 따라 전망대 전용 영상 보기 창을 추가했다. 영상은 열었을 때만 로드하며 재생 컨트롤, 전체 화면, 영상 전환, 닫기를 제공한다. 열 때 산책을 일시 정지하고 닫을 때 영상도 정지한다. 내부는 이전 빈 공간을 유지한다.

공개 배포 파일: public/media/bitgaram-observatory-interior.mp4 및 aerial.mp4. 실제 사진을 창밖 3D 배경으로 적용한 것은 아니다.
