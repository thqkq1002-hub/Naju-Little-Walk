# 전망대·배메산 항공사진 보강

## 확인 자료

- 사용자 제공 강산뉴스 워터마크 항공사진: 중앙 개구부가 있는 타원 지붕, 층을 이룬 은색 외장, 높은 지지 기둥, 하부 출입 공간, 숲 밀도를 관찰.
- 사용자 제공 나머지 2장은 도시 계획 조감도. 현재 완공 상태의 증거로 사용하지 않음.
- [한국관광공사 관광 정보](https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=33bff88a-0e1f-4f32-8c2a-18c66da3e649).
- 기존 작업에서 확인한 [현장 탐방 영상](https://www.youtube.com/watch?v=tQJsYaXqsIg)의 숲길·난간과 기존 Esri 위성영상 대조를 유지. 이번 수정에서 새로운 영상 장면을 관찰했다고 주장하지 않음.
- 배메산 식생 경계는 저장된 OSM way 508048953. 호수·도로 위치도 기존 OSM 자료 유지.

## 수정

- 막힌 타원판 지붕을 열린 타원 고리로 교체. 지붕은 공원 전체 보기에서도 표시.
- 은색 외장 띠, 외장 이음새, 하부 기둥 6개와 출입구 마감 추가.
- 배메산 경계 내부에 수관 1,375개 추가. 정상 쉼터·기존 접근로는 비워 둠.
- 기둥 몸체와 받침 충돌 정보를 공원 world JSON에 반영. 기존 높은 시작점과 계단 동선 유지.
- 회전 지도에도 같은 공원 Blender 객체를 넣어 단순 원판 전망대와 교체.
- 전망실의 지붕·외장도 같은 구조로 동기화. 실내 전체 보기에서만 지붕을 숨기는 기존 탐험 방식을 유지.

## 추정과 제한

지붕 치수·기둥 수와 위치·내부 코어·식생 개체 위치는 사진에서 비례를 추정했다. 실측 재현이 아니다. 실제 지형 측량 높이와 나무 종류는 확보하지 못했다. 공원 전체 산책망, 모노레일 운행, 하부 전시관 내부는 추가하지 않았다.

이전 Blender 수정본은 보존했다. 새 원본은 `outputs/bitgaram/bitgaram-park-aerial-detail.blend`, 회전 지도는 `outputs/bitgaram/bitgaram-overview-aerial-detail.blend`.

검증: Blender 조감 렌더 확인. 지붕 개구부와 기둥 충돌 회귀 검사 포함 이동 테스트 69개 통과.

## 추가 외관 대조

[2017년 현장 사진](https://live112.tistory.com/4710)의 전체 외관, 둥근 입구, 안내판 사진을 브라우저에서 직접 관찰했다. 한쪽을 감싸는 넓은 은색 외장과 길게 열린 창, 푸른 유리 로비, 은색 수직 창틀, 출입문·청색 안전 띠·점자블록을 추가했다. 2017년 사진이므로 현재 세부 상태를 보증하지 않는다. 방향과 치수는 추정이다.

[KRIC 2021년 외관 사진](https://www.kric.go.kr/v2/UserFiles/Image/2021/07/20/pj210720_03.jpg)을 다시 직접 보고 하부 전시동의 경사진 은색 외장·짙은 창·주황색 패널을 추가했다. 전시동 위치와 윤곽은 기존 OSM way 908801772를 유지했고 높이만 추정하여 충돌 정보에 반영했다.

추가 수정본은 `bitgaram-park-entry-detail.blend`이며, 이전 aerial-detail 수정본도 보존한다. 입구 로비는 외관이며 별도 전망실 진입 방식은 유지한다. 원본 사진을 배포 자산으로 복사하지 않는다.
