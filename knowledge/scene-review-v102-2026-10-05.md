# 빛가람·느러지·수국길 재점검 v102

2026-10-05 요청에 따라 빛가람 v101과 느러지 v100을 브라우저와 실제 배포 GLB로 다시 점검했다.

## 발견 및 수정

느러지 `boardwalk` 도착점은 목재 데크로 안내되지만 실제 GLB에서는 숲길 전체가 `Neureoji99_path_aggregate` 재질을 사용했다. v99 스크립트가 두 길의 material slots를 비우고 모든 면에 콘크리트를 지정하면서, v94에서 구분했던 끝부분 목재 표현도 사라졌다. 실제 브라우저의 수정 전 화면에서도 같은 문제가 확인됐다.

v100 Blender 원본을 보존하고 `outputs/neureoji-v102/neureoji-boardwalk-v102.blend`에 별도 저장했다. 기존 z < -190 구간의 395개 면에 자체 제작 목재 텍스처를 복원하고 해당 면의 UV를 원래 스케일로 되돌렸다. 콘크리트 접근로·수국 식재·전망대와 나머지 재질은 유지했다. 웹 화면에서 새로 기하를 생성하지 않는다.

## 실제 자료와 추정의 구분

기존 v94의 현장 사진 해석 및 OSM 중심선을 유지한다. 이번 변경은 기존 모델의 재질 퇴행 수정이며 현장 재측량이나 최신 항공영상에 따른 구간 확정이 아니다. 데크 전환 좌표, 판재 치수와 개별 식재는 기존 추정이다. 사진은 새 배포 텍스처로 사용하지 않았다. 지면 표고 45.76368m, 상층 데크 57.76368m, 구조 전체 높이 15.35m와 DEM 해석의 한계도 유지한다.

## 점검 범위

- 느러지 정상 전망, 수국 언덕길, 그늘 수국길, 숲길 끝 데크를 브라우저에서 확인했다.
- 빛가람 야외 계단과 실내 계단 갤러리를 확인했다. 새로 확인된 결함이 없어 v101 모델은 유지했다.
- 전망대 모든 층의 왕복, 두 수국길의 왕복, 모노레일 왕복·문·승하차, 빛가람 양쪽 계단과 연결부, 지형과 충돌면 일치 여부를 자동 검사했다.
- 새 테스트는 실제 GLB의 삼각형 위치와 재질을 대조하여 목재 데크가 콘크리트 일괄 교체에 다시 포함되지 않도록 검사한다.

총 116개 검사(공통·빛가람·표고 101개, 느러지·수국·식생·데크 15개)가 통과했다. 빌드·원본 보존·기하 동일성 검사 결과는 `sources/neureoji-v102/verification.json`에 기록한다. 보행면과 충돌 정보는 변경하지 않고 장소 JSON의 리비전·Blender 출처·추정 한계만 갱신했다.

모델 gzip은 16,750,540바이트로 16MiB 예산을 유지한다. OSM·ODbL 안내를 유지하며 Blender 파일과 라이브러리·도구·참고 사진은 웹 배포에 포함하지 않는다. 새 Blender 수정본은 GitHub Release에 별도로 보존한다.
