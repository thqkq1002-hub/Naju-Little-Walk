## 실제 위치 기반과 추정 구분

실제 위치 기반: OSM 보행로 중심선, 도로, 주차장, 노래비·화장실·쉼터 지점. 위성영상에서 추적한 강변과 솔밭·농경지의 큰 형태.

추정: 소나무 개체 수와 정확한 식재점, 수고·가지 형태, 강 수위, 지형 높이, 벤치 수량, 쉼터의 치수·지붕 세부, 도로와 길의 폭, 농작물 종류. 측량 또는 완전한 실사 복원으로 표기하지 않는다. 정자 두 곳은 OSM상 쉼터이므로 특정 역사 정자의 정확한 재현이라고 단정하지 않는다.

## Blender 제작

`scripts/build_deudeulgang.py` → `outputs/deudeulgang/deudeulgang-pine-grove-v2.blend` → `scripts/finish_deudeulgang_landscape.py` → `deudeulgang-pine-grove-v3.blend` → `public/models/deudeulgang.glb` 및 `.gz`.

소나무는 4가지 가지 형태, 뿌리·수피 틈·붉은 상부 줄기·솔잎으로 제작했다. 근거리와 원거리 메시를 Blender에서 각각 작성하고 기존 Three.js 인스턴싱/거리 전환을 사용한다. 노래비, 벤치, 나무 줄기와 강에는 충돌 데이터를 함께 만든다.

솔밭 소나무 280그루, 서쪽 배경 수목 170그루를 배치했다. 직접 작성한 솔잎·수피 텍스처를 사용하며 솔잎은 glTF MASK 재질로 내보내 깊이 기록과 인스턴싱을 유지한다. 강 건너 산등성이는 연속 메시이며 높이는 추정이다. 브라우저 프레임률 수치는 측정하지 않았다.

## 전체 맵 채색

`scripts/color_all_maps.py`가 현재 배포 중인 모든 기존 GLB를 Blender로 불러와 수목, 흙·목재, 물·유리, 건축 중성색 계열을 조정한다. 새 전체 장면 `.blend`는 `outputs/palette-v51`에 저장하며 기존 사용자의 작업 파일은 덮어쓰지 않는다.

Blender의 glTF exporter로 색상 재질을 내보내고, 이 값을 기존 GLB의 재질 항목에만 옮긴다. 정점과 이미지가 든 BIN 청크, 노드, 애니메이션, 충돌 데이터는 유지한다. 이 방법은 앞서 수정한 양자화 지오메트리의 재손상을 막는다. 재질 변경 내역과 BIN 해시는 `sources/palette-v51`에 기록한다.

사진·전시 패널·파노라마·텍스처와 투명·발광 재질은 보호한다. 현장 모든 건물의 실제 도장색을 확인한 것은 아니며 전체 자연색 조화를 위한 미술적 채색이다.

## 확인 결과

- 기존 GLB 17개, 재질 1,894개 색감 조정. 사진·투명·발광 등 보호 재질 항목 343개.
- `scripts/verify_palette.py`: 전체 모델의 BIN 청크, 지오메트리와 이미지, 노드·애니메이션 및 보호 재질 동일성 검사 통과.
- 기존 이동 73개와 드들강 3개 검사 통과. 실제 OSM 보행로 두 구간을 0.5m 간격으로 검사해 충돌 없는 연속 통행을 확인했다.
- 빛가람 양자화 좌표 회귀 검사, 지붕·벽 색상 및 식생 거리 전환 검사 통과.
- 새 모델을 포함한 모든 GLB를 무손실 gzip으로 전달한다. 브라우저에서 걷기 전환, 솔잎 표시, 전체 지도 연결을 확인했다. 평면의 그림자 줄무늬와 새 장소의 근거리 식생 전환도 보정했다.
- TypeScript 검사와 정적 배포 빌드 통과. 프레임률은 별도로 측정하지 않았다.

## 노송·숲 바닥·수변 보강 v54

2025년 오마이뉴스 강변 사진 3장과 보관된 Esri 위성영상을 다시 직접 확인했다. [2026년 5월 나주시니어신문 현장 기사](https://naju-senior.com/opinion/20621/)로 노송 숲길·정자·강변 식생의 구성을 교차 확인했다. 촬영일이 다른 자료이므로 현재 모든 시설 상태가 동일하다고 단정하지 않는다.

`scripts/detail_deudeulgang.py`는 기존 v3 편집본을 읽어 `outputs/deudeulgang/deudeulgang-pine-grove-v54.blend`를 새로 저장한다. 기존 파일과 직접 작성된 솔잎·수피 이미지는 보존한다.

- 4가지 소나무의 근거리·원거리 쌍에 동일한 줄기 굽힘과 가지 확장을 적용한다. 뿌리 위치와 기존 충돌 범위는 유지한다.
- 각진 솔잎 바닥 조각을 작은 방사형 색 전이와 마른 솔잎·잔가지로 바꾼다. 흙길 양옆은 완만한 색 경계로 연결한다.
- 기존 강안 윤곽을 따라 젖은 흙·낮은 둔덕·수변 풀을 배치하고 버드나무의 늘어진 잎을 보강한다. 강의 통행 금지 경계는 그대로다.
- 지도에 있는 쉼터의 계단처럼 쌓인 지붕을 경사진 합각 형태·기와 골·처마 목재로 다듬는다. 특정 역사 정자의 실측 복원은 아니다.

수형·수고·솔잎·개체별 식재, 둔덕 높이·갈대류 위치, 지붕 치수는 사진을 참고한 추정이다. 새 소품·수변 식생은 보행로를 피하며 낮은 지면 상세에는 그림자를 끈다. 소나무 인스턴싱과 60m 거리 전환, 솔잎 MASK 재질을 유지한다. 사진 파일을 모델 텍스처로 재배포하지 않는다.

검증: 기존 이동 및 드들강 전용 검사 총 76개 통과, TypeScript와 Vite 빌드 통과. Blender 숲길 렌더를 직접 확인하고 브라우저에서 모델 로딩·산책 전환·오류 없음까지 확인했다. GLB 11.14MB, gzip 4.31MB이며 정확한 프레임률은 측정하지 않았다.

## 강 건너 배경 산 보강 v55 — 2026-09-21

사용자가 배경으로만 보이는 산의 성긴 나무와 삼각형 얼룩을 지적했다. 보관된 강 건너 숲 사진과 위성영상의 큰 구성을 참고해, 배경에 한해 이어진 수림 표면으로 바꿨다. 산의 실측 높이·정확한 식생 분포를 재현한 것은 아니다.

`scripts/refine_deudeulgang_backdrop.py`는 v54와 중간 편집본을 보존하고 새 `outputs/deudeulgang/deudeulgang-pine-grove-v55-finished.blend`를 저장한다. 기존 배경 소나무 170개를 제거하고, 작은 수관 굴곡을 가진 연속 숲과 완만한 뒤쪽 능선을 4개 불투명 메시로 구성한다. 강 건너 둔덕 끝은 기본 지면보다 약간 높여 겹치는 면을 피한다. 가장자리에는 낮은 수변 수림의 높이 변화를 이어 붙인다.

수관 표면은 내장 image_gen 도구로 새로 제작한 `assets/deudeulgang/mixed-forest-canopy-v55.png`다. 소나무·활엽수 혼효림을 표현한 AI 생성 텍스처이며 실제 현장을 촬영한 사진이나 복원 자료로 표기하지 않는다. 원본 사진은 참고만 하고 재배포하지 않는다. 생성 프롬프트는 `sources/deudeulgang/background-texture-v55.md`에 보관한다. Blender에 이미지를 패킹해 편집본과 GLB가 외부 이미지 경로에 의존하지 않는다.

산과 수관에 `background_only`, `no_shadow`, `no_receive_shadow`를 기록한다. 웹 표시에서는 이 속성을 사용해 배경이 산책 장면의 제한된 그림자 영역에 들어가면서 생기는 얼룩을 방지한다. 나무를 클릭하거나 산으로 이동하는 기능을 추가하지 않는다. 기존 보행 장소 JSON과 진입 금지 경계는 그대로 유지한다.

모델 용량과 배경 메시 수는 `sources/deudeulgang/background-v55-metrics.json`에 기록한다. 배경은 불투명한 공유 텍스처를 사용하며, 앞쪽 산책 숲의 기존 소나무 인스턴싱·거리 전환은 유지한다. 실제 프레임률은 별도로 측정하지 않았다.

검증: 드들강 이동·식생 거리 전환·배경 불투명성·텍스처 포함 검사 7개 통과. TypeScript와 정적 빌드 통과. Blender 렌더와 로컬 브라우저의 전체 보기 회전·산책 모드에서 수림 표면을 확인했다. 새 모델은 GLB 17.28MB / gzip 9.61MB, 배경 4개 메시·126,848삼각형이다. 추가 텍스처 때문에 다운로드 용량은 이전보다 증가하며 FPS 향상을 수치로 보장하지 않는다.
