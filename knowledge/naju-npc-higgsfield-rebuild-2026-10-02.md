# 지역 안내 캐릭터 힉스필드 재제작 견적과 교체 계획

작성일: 2026-10-02. 상태: 내장 image_gen 참조 12장 및 Higgsfield 3D Jutsu MCP 배돌이 샘플 1개 제작 완료. 기존 삭제·교체·운영 배포 미실행.

## 최신 진행 상태

후속 요청으로 배돌이의 실제 사진 기반 Meshy T2 샘플 1개도 생성했다. Meshy 계정 잔액 11 → 6으로 **5크레딧을 사용**했다. 사진 기반 자동 채색 최소 15크레딧은 현재 잔액을 초과해 포함하지 않았다. 힉스필드 잔액은 2,152.03으로 유지됐으며 이 두 계정은 별개다. [사진 기반 샘플 제작 기록](naju-baedoli-photo-sample-2026-10-02.md)을 참조한다. 운영 캐릭터 교체는 아직 하지 않았다.

사용자의 “mcp로 메쉬 생성해 보세요” 요청에 따라 3D Jutsu MCP의 클라우드 Blender에서 배돌이 메시를 직접 작성하고 GLB·BLEND를 저장했다. 이는 아래에 기술한 Meshy 이미지 자동 변환 경로와 다르다. 이번 샘플 전후 잔액 2,152.03 → 2,152.03크레딧으로 확인된 차감은 0이다. 정면·사선 실제 렌더와 GLB 구조 검증을 완료했다. 삼각형 70,624개인 정적 샘플이며 운영용 최적화와 배치는 아직 하지 않았다. [샘플 제작 기록](naju-baedoli-jutsu-sample-2026-10-02.md)을 참조한다.

## 요청과 범위

배돌이·버들낭자·홍돌이·선생님 네 원형을 힉스필드로 재제작한다. 새 결과를 검증한 뒤 기존 캐릭터를 삭제하고 기존 일곱 시작 위치에 교체한다. 마지막 사용자 요청에 따라 전체 비용을 먼저 보고한 뒤 생성한다. 배포 대상은 Vercel이다.

사용자 제공 캐릭터 매뉴얼의 외형·색·소품을 기준으로 한다. 기존 Meshy 초안의 왜곡을 참조 기준으로 복제하지 않는다. 선생님은 특정 실존 인물이 아닌 창작 교사다. 측면·뒷면은 원본 도면이 없어 입체화 설계로 구분한다.

## 확인한 비용

- 힉스필드 선택 계정 잔액: 2,152.03크레딧, Ultra. 조회 시점의 값이다.
- `gpt_image_2_5`, `variant=sunburst`, `quality=max`, `resolution=4k`, `aspect_ratio=1:1`, `count=1` 견적: 이미지당 15크레딧. 생성 작업은 제출하지 않았다.
- 최초 계획은 네 캐릭터 × 정면·옆면·뒷면 3장 = 12장, 참조 이미지 180크레딧이었다. 이후 사용자가 참조 이미지는 Codex에서 만들고 힉스필드는 3D 변환만 맡기는 방식으로 변경했다. **180크레딧 항목은 취소했고 실제 차감은 0이다.**
- 내장 image_gen으로 네 캐릭터 정면·옆면·뒷면 총 12장을 생성하고 `assets/npc/higgsfield-rebuild-20261002/references/`에 저장했다. 4K 옵션은 사용하지 않았다. 힉스필드 크레딧 없이 이미지 생성 도구 자체의 사용량이 적용된다. 최종 프롬프트는 같은 폴더의 상위 `prompts.json`에 기록한다.
- `count=4` 조회도 동일한 15크레딧을 반환했으므로 다중 결과 가격을 확정 근거로 쓰지 않는다. 각 참조는 독립적인 한 장 요청으로 계산한다.
- 힉스필드 카탈로그에 Meshy `multi_image_to_3d`가 있고 최대 4개 시점, 채색·PBR·재메시·뼈대 옵션을 지원한다.
- 연결된 MCP에는 Meshy 이미지→3D 작업 제출·견적 도구가 노출되지 않았다. 별도의 3D Jutsu 도구는 연결되어 있으며 Blender 코드로 실제 메시를 제작할 수 있다. 공식 CLI의 `generate cost`가 자동 변환 견적 조회 경로지만 별도 CLI 인증이 필요하다. 클라우드 CLI에서 `Not authenticated`를 확인했다. MCP 로그인과 CLI 인증은 별개다.
- 로컬 `work/tools/higgsfield/`에 공식 CLI 1.1.26을 설치했다. 실행 파일은 처음 도움말 조회가 됐지만 이후 사라졌고, 공식 설치 프로그램으로 복구한 뒤 Windows가 ‘바이러스 또는 기타 사용자 동의 없이 설치된 소프트웨어’ 사유로 실행을 차단했다. 보안을 끄거나 예외를 추가하지 않았다. 이는 Codex 자동 승인 거절이 아니라 Windows 실행 차단이다.
- 따라서 **3D 생성 비용과 최종 합계는 미확정**이다. Meshy 직접 API 크레딧을 힉스필드 크레딧으로 환산하지 않는다. 가격 확정 전 생성하지 않는다. CLI 도구·캐시·인증 파일은 Git이나 배포에 넣지 않는다.
- MCP 업로드 슬롯 1개를 예약했으나 데이터 전송이 연결 도구의 명령 길이 제한으로 거부됐다. 업로드 확인이나 3D 작업 제출은 하지 않았다. 참조는 로컬 프로젝트에 준비되어 있으며 힉스필드 전달 완료라고 보고하지 않는다.

공식 안내: [힉스필드 CLI](https://github.com/higgsfield-ai/cli), [힉스필드 가격 안내](https://higgsfield.ai/mcp-pricing).

## 제작 기준

| 캐릭터 | 보존할 정체성 | 보완할 조형 |
|---|---|---|
| 배돌이 | 배 모양 노란 얼굴, 주황 모자, 파란 목수건, 배 소품 | 양발 접지, 모자 두께, 손가락과 배의 연결, 목수건 뒷면 |
| 버들낭자 | 올림머리와 금빛 장식, 분홍 상의, 청보라 긴 치마, 장식 띠 | 머리 뒤 구조, 얼굴의 입체감, 깃·소매·손, 자연스러운 치마 볼륨 |
| 홍돌이 | 넓은 홍어 몸, 흰색과 파란 강조, 장갑·파란 신발·꼬리 | 판처럼 보이지 않는 등·배 곡면, 팔 연결, 얼굴 조형, 꼬리 연결 |
| 선생님 | 친근한 창작 교사, 단정한 현대 복장, 책 | 자연스러운 손과 얼굴, 의상 주름, 편안한 서 있는 자세 |

정면·측면·뒷면은 같은 비례·색·소품·편안한 자세를 유지한다. 텍스트나 여러 캐릭터를 한 이미지에 넣지 않는다. 3D 생성에는 동일한 캐릭터의 시점만 넣는다. 이미지 최고 해상도가 3D 텍스처 최고 해상도를 보장하는 것은 아니다.

완성 모델은 Blender에서 눈·손·재질·접지·정면 방향을 보정하고 GLB로 내보낸다. 생성 원형은 조형용으로 충분한 세부를 확보하고, 앱에는 태블릿 성능을 확인한 최적화 파일을 넣는다. 현재 요청에 없는 대화·동작을 비용에 임의로 추가하지 않는다.

## 교체와 검증 순서

1. 3D 견적과 전체 합계, 재시도 한도를 보고하고 비용 승인을 받는다.
2. 참조 이미지 및 네 캐릭터를 별도 경로에 생성한다.
3. 원본 매뉴얼과 앞·옆·뒤를 비교하고 Blender 조형·채색·웹 성능을 확인한다.
4. 기존 모델의 앱 참조를 새 파일로 교체한다. 기존 일곱 지역 배정과 시작점은 유지한다.
5. 교체 확인 후 기존 제작 캐릭터 모델을 사용자 요청 범위에서 삭제한다. 사용자 제공 원본 매뉴얼·도시 지도·사용자 수정 Blender 파일은 삭제 대상으로 간주하지 않는다. Git 이력은 재작성하지 않는다.
6. 배치·이동 테스트와 빌드를 통과시킨 뒤 GitHub 푸시 → Vercel 자동 배포를 확인하고 장소별 화면을 촬영한다.

비용 미확정 상태에서 기존 운영 캐릭터를 삭제하지 않는다. 배돌이 MCP 샘플을 검토한 뒤 전체 제작 방식과 교체 범위를 확정한다. Meshy 자동 변환을 선택할 경우 해당 경로의 비용 확인이 필요하다.
