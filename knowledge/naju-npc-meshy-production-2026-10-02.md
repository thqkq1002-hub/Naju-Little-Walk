# 나주 NPC Meshy 제작 기록

작성일: 2026-10-02. 배돌이·버들낭자·홍돌이·일반 선생님 4종의 **채색 초안**이다. 앱 배치·애니메이션·배포는 아직 수행하지 않았다.

## 제작과 비용

- 사용자가 선택한 ‘형태부터 생성, Blender에서 채색’ 방식으로 Meshy T2 이미지→3D 작업 4건을 완료했다.
- 건당 5크레딧, 총 20크레딧 사용. 조회한 Meshy 잔액은 31 → 11크레딧이다.
- 원본 매뉴얼을 참고해 imagegen으로 정리한 정면 이미지를 사용했다. 원본을 그대로 잘라낸 사진이 아니라 AI로 재구성한 참조 이미지다. 선생님은 신규 디자인이다.
- Meshy 원본 GLB는 보존했다. Blender에서 앞면 참조 이미지와 측면·뒷면 추정 색을 조합하고, 2K UV 색상 아틀라스로 구웠다. 결과는 재질 1개이며 뼈대가 없다.
- 홍돌이는 생성 원본의 몸통이 매우 얇아 Blender에서 깊이를 늘렸다. 신장과 측면·뒷면은 제작용 추정이다.

공식 비용 근거: [Meshy API 가격표](https://docs.meshy.ai/en/api/pricing).

## 남은 품질 작업

검사 통과는 최종 캐릭터 품질 완성을 의미하지 않는다. 정면 이미지와 입체 표면의 맞춤에 일부 왜곡이 있고 측면·뒷면은 단순하다. 특히 홍돌이는 판을 두껍게 만든 듯한 형태와 분리된 장갑 부분을 수작업으로 연결·조형해야 한다. 얼굴과 의상 가장자리의 색 경계도 다듬어야 한다.

다음 단계는 Blender 조형 보정 → 리깅 → 접지·움직임 검증 → 앱 배치다. 추가 유료 재생성은 실행하지 않았다. 사용자 원본 `.blend`와 기존 앱 모델은 덮어쓰지 않았다.

## 힉스필드 재생산 비용 조회

2026-10-02 연결 도구에서 힉스필드 잔액 2,152.03크레딧과 Meshy 7 기반 3D 모델 지원을 확인했다. 그러나 현재 연결에 3D 생성·견적 전용 도구가 없어 실제 힉스필드 차감액은 확인하지 못했다. 이미지 견적 도구는 3D 모델 요청을 거부했다. 작업은 제출하지 않았다.

비교용 Meshy 직접 API 가격은 표준 모델 기준 형태만 20/개, 2K·4K 채색 포함 30/개다. 4종이면 각각 80·120 **Meshy API 크레딧**이며 힉스필드 크레딧으로 환산할 근거는 없다. 공식 힉스필드 가격 페이지: <https://higgsfield.ai/mcp-pricing>.

API 키와 다운로드용 서명 URL은 배포용 묶음에 넣지 않는다.
