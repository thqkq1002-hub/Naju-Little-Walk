# 다시초등학교 실내·운동장 탐험 MVP

## 사용자 요청

금성관처럼 실제 지역의 지도와 사진을 참고해 다시초등학교를 만들고 돌아다니기.

## 결과

- Blender 원본과 GLB를 별도로 제작했습니다. 기존 금성관 산출물은 유지했습니다.
- 실제 학교 부지와 건물 2개 윤곽, 사진을 참고한 외관을 모델링했습니다.
- `/?place=dasi`에서 학교를 탐험하고, 장소 링크로 금성관과 오갈 수 있습니다.
- 원형 장식과 벽돌 본관, 둥근 붉은 지붕, 잔디, 정문, 사진에 나타난 작은 파란 지붕 건물과 코트를 표현했습니다.
- WASD 이동, 드래그 시선 이동, 전체 조망, 충돌, 위치 지도, 터치 버튼을 재사용합니다.
- 본관 1층을 빈 공간과 벽으로 다시 제작해 열린 문으로 들어갈 수 있게 했습니다. 복도·교실·도서실은 가상의 체험 공간입니다.
- 문틀, 창문 개구부, 투명한 1층 창, 교실 책상 12개와 의자, 칠판, 책장과 책, 독서 테이블, 신발장, 실내 조명을 추가했습니다.
- 학교명은 글자 앞면이 벽을 향하던 회전 오류를 수정했습니다. 회전 후 세계 X 폭 대신 글자 자체의 가로·세로 치수로 크기를 계산합니다.
- 운동장·서쪽 주차장·남쪽 수목 구역을 항공영상과 대조해 분리했습니다. 남동쪽 건물, 야외 코트와 농구대·울타리, 보행로, 배수관·화단을 추가했습니다.
- 웹에서 정적인 불투명 물체를 재질별로 묶어 렌더링합니다. 투명한 창은 따로 두어 깊이 정렬을 유지하고, Blender 원본의 개별 물체는 보존합니다.

## 정확도

건물 윤곽은 지도 좌표지만 높이와 여러 세부 요소는 추정입니다. 운동장 구획은 2022년 항공영상의 시각적 추적이며 위치 오차가 있습니다. 남동쪽 건물은 기존 OSM 학교 경계 바깥까지 이어져 소유·소속은 확정하지 않았습니다. 실내의 교실 배치·가구는 창작이며 2층은 외관만 구현했습니다. 실제와 똑같은 사진측량 복원물은 아닙니다.

## 검증 방법

- Blender에서 GLB 내보내기와 조감도 렌더링.
- 조감도·간판 정면·교실·도서실 렌더를 열어 배치와 글자 방향 확인.
- TypeScript 및 정적 웹 빌드.
- 총 16개 자동 검사: 기존 금성관 회귀, 학교 윤곽, 운동장과 남쪽 길, 실내 왕복, 가구·벽 충돌, 간판 방향, 실내 위치 표시, 내장 GLB/텍스처, 렌더링 통합 전후 좌표 보존.
- 브라우저의 화면 캡처·직접 조작 테스트는 수행하지 않았습니다. 선택적 WebMCP 도구도 실제 지원 브라우저에서 검증하지 않았습니다.

원본과 확인 범위는 `sources/DASI_REFERENCES.md`에 기록했습니다.
