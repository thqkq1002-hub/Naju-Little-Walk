# 느러지 근거리 식생·수국 보완 v100

2026-10-05 사용자 요청에 따라 느러지 전망대와 수국길을 다시 검토했다. v99 원본을 보존하고 `outputs/neureoji-v100/neureoji-close-detail-v100.blend`에 별도 저장했다.

## 관찰과 자료

[2024-07-08 방문 사진](https://forme13.tistory.com/3621)과 [2026-07-10 현장 사진](https://localm.kr/bbs/board.php?bo_table=news&me_id=4&wr_id=4488)의 둥근 꽃 군집, 잎, 도로와 숲바닥의 경계를 대조했다. 사진은 조사 자료로만 사용했고 배포 텍스처로 사용하지 않았다. 이번 작업에서 현장 지면 표고나 개별 꽃·풀의 좌표를 새로 측량하지 않았다.

실제 배포 GLB의 꽃 중심부 재질은 MASK와 0.38 cutoff를 사용했다. 잎의 실루엣을 잘라내는 표현이 꽃 중심부의 입체 표면에도 적용되어 작은 구멍과 얇은 면을 만들고 있었다. 이는 모델의 렌더링 관찰이며 현장의 식생 상태에 대한 사실이 아니다.

## 변경

- 6개 수국 중심부 배치에 불투명 PBR 재질을 적용했다. 꽃 중심부에는 새로 자체 제작한 촘촘한 꽃잎 질감 3종을 사용하며 잎·원경 수관에는 기존 alpha MASK를 유지했다.
- 기존 꽃·잎의 좌표, 수형, 줄기와 꽃잎 기하를 유지했다. 꽃이 구멍을 통해 사라지는 현상을 교정하는 데 집중했다.
- 도로 밖에 낮은 풀 군집 136개(816개 휘어진 잎날, 4,896개 정점)를 하나의 배치로 추가했다. 높이는 최대 21cm이며 표시 지형에 뿌리를 정렬했다. 개별 위치와 종은 자연스러운 연결을 위한 추정이다.
- 보행 바닥·충돌 solids·지도 좌표·강·전망대 구조·고도는 유지했다. 장소 JSON은 새 Blender 출처와 추정 한계를 기록하고 캐시 버전을 갱신했다.

지면 모델 높이는 45.76368m, 상층 데크 57.76368m, 구조 전체 높이는 15.35m다. 이는 기존 DEM 기반 지면 해석과 사진 참고 치수이며 현장 실측 고도가 아니다. 자세한 표고 판단은 v98 기록을 따른다.

## 검증

공통 이동 74개와 느러지·식생·표고·새 재질 및 길 밖 식재 검사 17개가 통과했다(총 91개). 새 검사는 실제 GLB에서 꽃 중심부가 불투명인지, 잎의 alpha MASK가 남아 있는지, 좌표 압축 후 추가 풀의 모든 정점이 두 보행로 밖에 있는지를 확인한다.

보호 메시 70개, 보행 삼각형 및 원본 v99 Blender 해시를 유지한 것으로 검증했다. gzip 해제 결과와 원본 GLB, 정적 빌드의 gzip이 동일하다. production 빌드와 숲길·상층 브라우저 확인을 수행했다. 기존 큰 번들 크기 경고는 남는다.

메시 수는 97개, gzip 전송량은 16,744,896바이트이며 16MiB 예산 이내다. 사진·Blender·도구·라이브러리·임시 압축 파일은 웹 배포에서 제외한다. OSM·ODbL 및 기존 DEM 출처 안내를 유지한다.

소스는 GitHub main에 병합하고 기존 운영 브랜치의 자동 배포로 게시한다. v100 Blender 파일은 별도 GitHub Release `neureoji-close-detail-v100-20261005`에 보존한다. 운영 반영은 Vercel 상태와 장소 JSON·모델 SHA-256을 대조한 결과로 보고한다.
