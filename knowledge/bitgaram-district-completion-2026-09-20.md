# 빛가람동 전체 전경 보강

## 범위와 기준

사용자가 지정한 `place=bitgaram`의 회전 가능한 전체 전경을 보강한다. 기존 `bitgaram-drone-detail.blend`에서 시작해 새 Blender 수정본을 저장한다. 한전·호수공원·전망대·KENTECH의 별도 산책용 모델이나 충돌 정보는 변경하지 않는다.

## 확인 자료

- OpenStreetMap 공개 Map API: 2026-09-20, 경도 126.765–126.822 / 위도 34.998–35.035. `district-2026-09-20.osm`과 변환 JSON을 별도 보존했다. 기존 원본은 유지했다.
- [Esri World Imagery](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer): 2000×1600 영상을 직접 열어 남부·동부 저층 주거지, 아파트 단지, 주변 농지·녹지 분포를 확인했다. 촬영일 미확인. 요청 범위와 응답 범위가 다르므로 실제 응답 extent를 별도 보존하고 좌표 변환에 사용했다. 원본 사진은 `work/`에서만 대조하고 배포하지 않는다.
- 사용자 제공 드론 영상의 기존 추출 프레임 `work/observatory-video/0-1.png`: 호수 둘레 아파트 군집, 녹지, 남쪽 저층 시가지의 상대적 밀도를 다시 확인했다.
- [2025-04-01 뉴시스 현장 기사](https://www.newsis.com/view/NISX20250401_0003121954): 미착공 주택 용지가 존재한다는 설명을 확인했다. 공터 전체를 임의 건물로 덮지 않는다. 기사에 표시된 전경 사진 날짜는 2023-03-22이며 현재 촬영이라고 취급하지 않는다.

## 반영

1. 새 OSM 건물 중 기존 모델과 중복되지 않는 윤곽을 추가한다. 명시된 높이·층수 우선, 없는 높이는 건물 용도별 추정이다. 창 띠·옥상 난간·설비는 전경용으로 단순화했다.
2. 사진에서 선택한 저층 주거지 6구역의 밝은 지붕 후보를 추린다. 기존 건물·수면·도로와 겹치는 후보는 추가하지 않는다. 이 모델은 사진 해석에 따른 추정 건물이며 측량 윤곽이 아니다. 지붕과 포장면을 완벽하게 구분하는 자동 검출이라고 주장하지 않는다.
3. OSM 토지 이용 구역, 주차장·운동장·공원·추가 도로를 색과 바닥 마감으로 구별한다. 공터·농지·녹지는 실제 용도와 구획이 드러나도록 한다.
4. 도로 가장자리와 공원·주거지 여유 공간에 수목을 보강한다. 개별 위치·수종·수량은 추정이다.
5. 위성사진에서 확인한 외곽 농경·수림 구역을 모델링한다. 외곽 경계는 사진 해석이고 내부 필지선·고랑 간격은 전경 표현을 위한 추정이다.

## 성능·검증

Blender 수정본을 먼저 저장한 후 내보내기에서 정적 재질별 메시를 묶는다. 전달용 GLB와 gzip이 일치하는지 검사한다. 기존 세 장소 푯말, 모델의 유한 좌표·높이, 추가 건물 근거 기록을 검사한다. 실제 FPS를 측정한 것은 아니다. 출처 표시와 ODbL 안내를 유지한다.

추가 수량과 건물별 추정 여부는 `sources/bitgaram/district-completion-metrics.json`에 기록한다. 현재 모든 실제 건물과 필지를 완전 실측·복제한 모델은 아니다.

최종 추가: 지도 건물 81동, 위성 해석 추정 건물 207동, 토지 이용 구획 104곳, 주차장 42곳, 운동장 45곳, 도로 조각 1,808개, 수목 4,650그루, 추정 농경 필지 470개. 기존 전경용 위치·법선 압축 스크립트를 적용했으며 위치 저장의 최대 축별 오차 상한은 약 0.035m이다. 최종 전송 파일은 약 15.8MB이며 Blender 편집본은 원래 정밀도를 유지한다.

게시 저장소의 단일 객체 크기 제한에 맞춰 삼각형을 16비트 인덱스 묶음으로 분할했다. 이 단계는 위치·재질·삼각형을 생략하지 않는다. 1,691,742개 삼각형을 보존하며 최종 정확한 파일 크기는 metrics JSON 기준이다.

최종 전경은 두 GLB로 나누어 동시에 불러온다. 두 장면의 원래 노드 변환을 유지한 채 합치므로 장소 위치와 외형이 바뀌지 않는다. 각각 약 24.9MB인 원본과 gzip 전송 파일을 저장한다. 편집용 `.blend`는 하나의 완전한 도시 모델이다.
