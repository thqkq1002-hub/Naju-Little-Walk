# 수목원 메타세쿼이아·활엽수 수형 보완

후속 계획 A/B/D의 나무 작업이다. 공개 수목원 v66 저장본을 보존하고, v73 첫 후보와 v74 밀도·수피 보완본을 별도 Blender 파일로 작성했다. v73은 렌더 대조에서 잎이 너무 성겨 게시하지 않았으며, v74를 로컬 운영 모델에 적용해 검증했다.

## 실제 사진과 기존 형상 대조

[2021-06-13 게시 방문 기록](https://hangamja.tistory.com/1607)의 메타세쿼이아길 사진과 서쪽 목재 데크 사진을 브라우저에서 확대해 직접 확인했다. 가로수는 높은 줄기 사이에서 잎이 달린 가는 가지가 이어져 터널을 만든다. 데크 옆 활엽수는 큰 갈라진 가지와 작은 잎 사이에 빈틈이 보인다. [한국관광공사 여행기사](https://korean.visitkorea.or.kr/detail/rem_detail.do?cotid=0eac8ebd-3748-414a-83ba-6ca7ab0bedc9)는 2024년 11월 작성 자료임을 밝히며 가로수길·활엽수원·목재 데크를 소개한다. 사진의 현재 날짜·개별 나무 높이는 확정하지 않는다.

| 대조 항목 | 기존 저장본 | 이번 수정 |
| --- | --- | --- |
| 메타세쿼이아 잎 가지 | 13층 × 3개의 둥근 수관 반복 | 줄기·기존 가지를 보존하고 가는 잔가지와 양쪽 잎이 달린 자체 제작 잎 묶음 |
| 활엽수 잎 | 21개의 큰 수관 덩어리 | 작은 휘어진 잎 묶음, 빈틈과 잔가지 |
| 반복 수형 | 각 종류 하나의 공유 형상 | 종류마다 세 변형, 같은 위치의 가까운/먼 짝 |
| 위치·시설·길 | v66 지도 배치와 v65 도로 | 변경하지 않음 |

메타세쿼이아 120그루와 활엽수 1,071그루, 가까운/먼 객체 총 2,382개를 보완한다. 보호 메시 13,345개의 정점·면·변환, 기존 나무 목재 면과 높이, 식재 변환과 가까운/먼 쌍, 보행 JSON을 별도로 검사한다. 큰 수관 대신 작은 내부 잎 볼륨과 얇은 잎 묶음을 함께 사용한다. 도면이나 실측에 의한 수종·수량·치수 확정 작업은 아니다.

참고 사진은 배포 텍스처로 복사하지 않는다. 잎 질감은 자체 절차 생성 그림이며 실제 사진·실사 스캔으로 표시하지 않는다. 계절·식재 밀도·바닥 색·일반 활엽수의 수종 배정은 기존 추정 상태다. 실제 Android 프레임과 회전 검증도 남아 있다.

## 검증 상태

v73은 보호 메시 13,345개·기존 목재·높이·식재 변환·1,191개 가까운/먼 쌍·보행 JSON 검사에 통과했다. 동일 카메라 렌더에서는 넓은 수관 덩어리가 줄었으나 메타세쿼이아 잎 밀도가 실제 사진보다 낮아 게시하지 않았다. v74는 가까운 잎 가지 3→7개, 먼 잎 가지 2→4개를 각 잔가지에 배치하고, 가는 잎 아틀라스의 밀도와 자체 제작 회갈색 수피를 보완했다. 저장본을 다시 열어 같은 보존 검사를 통과했고, 같은 카메라의 길·숲·수관 렌더 세 장을 확인했다.

이동·수목원 테스트 82개와 TypeScript, Vite 빌드가 통과했다. 데스크톱 인앱 브라우저의 1024×768, 844×390 화면에서 산책로와 UI를 확인했고 오류·경고는 없었다. 844×390 최근 120프레임 간격 평균은 24.58ms, p95는 33.4ms였으며 이는 한 지점의 데스크톱 관측값이다. 실제 Android 성능 또는 개선 전후 FPS 비교로 해석하지 않는다.

gzip은 9,725,479→11,472,045바이트(약 18% 증가), 공유 형상 면 수는 272,942→315,860으로 증가했다. 나무 반복 객체를 모두 가까운 형상으로 환산한 면 수는 17,012,754→8,362,602, 모두 먼 형상으로 환산한 값은 5,706,522→4,000,338이다. 변형 세 종류 때문에 공유 형상 수는 늘었지만 반복 배치에 쓰는 각 형상은 가벼워졌다. 실제 화면에서는 가까운/먼 형상과 가림 처리가 함께 작동하므로 환산값은 화면 렌더 면 수와 다르다. 전체 퀄리티 계획과 실기기 검증은 계속 진행 중이다.
