# 느러지 수국 보강 v95

[레퍼런스 조사와 변경 계획](neureoji-hydrangea-v95-plan-2026-10-04.md)을 바탕으로 v94h를 보존하고 v95 a·b·c 편집본을 제작했다. 최종 Blender 원본은 `outputs/neureoji-v95/neureoji-hydrangea-v95c.blend`다.

- 수국·산수국 749개체, 둥근 꽃송이 2,149개, 산수국 꽃송이 1,596개를 제작했다. 개체 수는 사진 참고 배치 수이며 현장 식재 수를 실측한 값이 아니다.
- 네 갈래 꽃받침 84,612장, 톱니 잎·잎맥을 표현한 넓은 잎 33,705장을 만들었다. 낮은 잎 군집으로 빈 줄기와 바닥이 보이는 부분을 줄였다.
- 일부 구간을 엇갈린 두 줄로 채우고 높낮이·폭·꽃 위치를 달리했다. 전화부스 주변은 자홍색·분홍색, 전망대 쪽은 청색 산수국을 참고했다.
- 기존 길·난간·충돌·강 경계·정상 시선은 유지했다. 이동 솔리드 목록의 SHA-256은 `model.json`에 기록했다.
- 첫 보강본의 용량을 줄이기 위해 표시용 꽃받침 수와 불필요한 텍스처 좌표를 정리했다. 꽃과 일부 가까운 나뭇잎만 정수 좌표로 저장하고 균일한 크기 변환으로 법선 방향을 유지했다. 정밀 Blender 원본은 그대로 보관한다. 바닥·강 위치에는 이 좌표 압축을 적용하지 않았다.
- 기존 15MiB 전송 한도는 입체 꽃과 잎이 늘어난 이번 수정본에서 **16MiB**로 조정했다. 공통 25MiB 한도보다 엄격한 장소별 예산은 유지한다. 최종 용량과 장식 식물의 최대 좌표 차이는 `knowledge/sources/neureoji-v95/model.json`에 기록한다.

여름 개화 모습이며 현재 개화 상태가 아니다. 폭·개별 식재·치수는 사진 참고 추정이고, 고도는 기존 30m DSM의 지면 추정이다. [2026-06-27 직접 방문 사진](https://akekanfl.tistory.com/8708274)을 형태 대조에 사용했고 [2026-06-19 현장 취재](https://naju-senior.com/local-news/21984/)를 보조로 확인했다. 신문 원본 사진 링크는 열리지 않아 시각 근거로 주장하지 않는다.

## 제작·검증 순서

1. `refine_neureoji_hydrangea_v95.py`로 새 식재를 Blender에서 제작한다.
2. `finish_neureoji_hydrangea_v95.py`로 원본을 보존한 다음 표시용 입체 꽃 디테일을 정리한다.
3. `compact_neureoji_plants_v95.py`로 장식 식물의 저장 좌표만 압축한다.
4. 기존 바닥 대조·계단·경사 길 왕복 검사를 실행하고 타입 검사·정적 빌드·실제 화면을 확인한다.
5. GitHub·Vercel 공개 버전의 모델·데이터를 로컬 검토본과 비교한다.

전체 작업 자료는 [비공개 프로젝트 보관 계획](github-project-archive-2026-10-04.md)에 따라 원본·이전 버전·참고 자료까지 별도 GitHub Release로 보관한다.

## 배포 확인

[Vercel 수국길](https://naju-little-walk.vercel.app/?place=neureoji&at=hydrangea&v=neureoji-hydrangea-v95c)을 실제 브라우저 1280×720에서 확인했다. 화면이 정상 렌더링됐고 콘솔 오류는 없었다. 모델·지도 데이터·HTML·주요 실행 파일이 로컬 검토본과 일치한다. [배포 대조 기록](sources/neureoji-v95/deployment.json)에 검사값을 보관했다.

느러지 검사 8개, 공통 이동 검사 74개, 타입 검사와 정적 빌드를 통과했다. 이전 v94에 기록한 별도 빛가람 경로 검사 2개 실패는 이번 장소 변경과 무관하며, 전체 테스트가 모두 통과했다고 주장하지 않는다. 안드로이드 태블릿 실기기 검증은 수행하지 않았다.
