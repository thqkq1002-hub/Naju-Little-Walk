# 빛가람 장소별 산책 — 제작 기록

## 숲 경계·호숫가 보강

OSM natural=wood 508048953 배메산 경계를 이용해 기존 사각형 녹지 색을 교체했다. 경계 양쪽 10m는 색을 부드럽게 연결하며 이는 시각적 표현이다. 저장된 OSM 보행로를 배경 지형에 맞춰 표시하고, 실제 호수 윤곽에 가장자리 띠를 추가했다. 보행로 높이·폭, 가장자리 재질은 추정이다. 새 배경 경로는 산책 범위를 확장하지 않으며 기존 보행 충돌 데이터는 유지한다.

넓은 지면·호수와 언덕이 국소 그림자 영역에서 자기 그림자를 생성하지 않도록 조정했다. 높은 공원에서 처음 위치로 돌아갈 때 시작 높이 16m가 유지되도록 수정했다. 원본 `bitgaram-park-detail.blend`를 보존하고 새 `bitgaram-park-landscape.blend`를 생성한다. 생성 스크립트: `scripts/refine_bitgaram_landscape.py`.

## 회전 지도와 공원 보강 (2026-09-15)

기존 영산포는 `app/page.tsx`에서 Blender GLB를 Three.js로 불러오고, 카메라 궤도 회전·확대와 보행을 처리한다. 최초 빛가람 안내 화면만 PNG였으므로 회전할 수 없었다. 동일한 Blender 원본을 `export_bitgaram_overview.py`로 GLB 내보내고 `bitgaram-orbit.tsx`에서 회전·확대·각도 초기화를 구현했다. 푯말은 OSM 중심 좌표를 매 프레임 화면에 투영하므로 회전을 따라간다. 전체 지도에서는 장소 선택만 하고 개별 맵에서 걷는 범위는 유지한다.

공원은 이전에 직접 확인한 위성 윤곽·철도산업정보센터 사진·Where’s Anne 영상의 숲길과 조명을 참고하여 수목 밀도·목재 데크 이음·보행등을 보강했다. 지형이 평지와 겹치던 가장자리의 깊이 충돌을 제거했다. 개별 수목·조명 위치는 추정이다. 새 편집본은 `outputs/bitgaram/bitgaram-park-detail.blend`이고 이전 원본은 보존했다. 시작 안내문을 가리던 푯말은 산책 중에 표시한다.

추가 검색 자료: [전망대와 모노레일 방문 기록](https://mnetv.com/1505). 본문에서 외부 계단·승강장·목재 동선을 교차 확인했으며, 이 기록만으로 정확한 시설 치수나 현재 운영 상태를 단정하지 않는다.

## 작업 범위와 중단 기준

- 전체 빛가람은 안내용 조감 화면. 푯말을 누르면 독립된 장소 맵으로 진입.
- 호수공원은 전망대 주변에 집중하고 전망대 내부 포함.
- 한국전력 본사와 KENTECH는 외관·입구 주변과 1층만.
- 2026-09-15 작업 시작 시 Codex 주간 잔여 60%. 잔여 50% 이하 확인 시 작업을 저장하고 중단. 다른 작업도 공유하는 계정 한도이며 토큰 개수로 환산하지 않음.

- 전망대: OSM way 656235304(배메산전망대). 대표 좌표 약 35.016925, 126.790447.
- 전시관리동: OSM way 908801772. 전망대 남쪽 별도 건물.
- [철도산업정보센터 외관 사진](https://www.kric.go.kr/v2/UserFiles/Image/2021/07/20/pj210720_03.jpg): 회색 비정형 전시동, 주황색 부분 외벽, 언덕 위 원형 전망실.
- [전망대 실내 사진](https://kr.trip.com/moments/detail/naju-si-1595529-130704646/): 곡면 유리창, 금속 창틀, 밝은 타일 바닥.
- [Where’s Anne 탐방 영상](https://www.youtube.com/watch?v=tQJsYaXqsIg): 1:36 숲길·조명, 2:40 계단실 손잡이, 2:50 유리문과 상부 실내 시설, 3:12 시가지 조망을 직접 확인. 과거 촬영이며 현재 배치와 동일하다고 단정하지 않음.
- [2019년 방문 기록](https://kdk4876.tistory.com/18172193): 하부 전시동과 전망실 동선의 보조 자료.
- [Esri World Imagery](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer): 126.784,35.013–126.796,35.021 구역을 직접 확인. 서쪽 호수, 중앙 동쪽 숲 언덕, 정상 원형 건물, 남쪽 관리동 배치를 대조. 촬영 연도는 확인되지 않았으며 영상 원본은 배포하지 않음.
- [한국전력 본사 로비 사진이 포함된 정책브리핑](https://www.korea.kr/briefing/policyBriefingView.do?newsId=148817032): 2016년 로비 사진을 직접 확인. 금속 원형 기둥, 밝은 석재 바닥, 안내 화면, 출입 시설, 화분을 참고. 한전KPS·전력거래소 로비는 다른 건물이므로 사용하지 않음.
- [KENTECH 공식 캠퍼스맵](https://home.kentech.ac.kr/campusMap.do): 완공 사진과 계획 조감도를 구분할 것. 구체적인 1층 배치 추가 확인 필요.

## 재현 수준

지도 윤곽은 실제 데이터, 지형 높이·실내 치수·가구 위치는 공개 사진 기반 추정이다. 내부를 임의로 채운 뒤 100% 재현이라고 표현하지 않는다. 기존 사용자 Blender 파일은 수정하지 않고 빛가람 전용 결과를 별도 생성한다.

## 구현과 검증

- Blender 조감 렌더와 3개 장소 푯말. 전망실은 공원에서 별도 맵으로 진입.
- 실제 OSM 윤곽을 사용한 호수·도로·건물. 도로를 나주 지역 이동 지도에도 통합.
- 공원은 정상 쉼터에서 하부 쉼터까지 제한된 접근 산책로. 하부 전시동 내부·공원 전체 산책망은 이번 초안에 포함하지 않음.
- 전망실은 곡면 유리창·창틀·중앙 승강기 코어·벤치·전망 안내대. 실내 치수와 시설 위치는 추정.
- 한국전력 OSM way 594386007은 낮은 기단과 타워가 합쳐진 윤곽. OSM 최대 높이 154m는 좁은 타워에만 적용하고, 17m 기단 및 타워 분리는 위성·[외관 사진](https://ojsfile.ohmynews.com/BIG_IMG_FILE/2023/0508/IE003147444_BIG.jpg)을 참고한 추정. 전체 윤곽을 154m 높이로 만들지 않음.
- KENTECH OSM way 1065747586의 약 46×27m 사각 윤곽과 Google Maps의 2022-07-09 완공 사진을 대조. 4층 유리·베이지 수평 띠·푸른 입구 패널을 참고. 2022-08 계획 조감도는 실제 완공 사진과 구분하며 사용하지 않음. 1층 동선과 안내 데스크는 추정이고, 2026년 캠퍼스 전체 재현이 아님.
- 위성 영상은 공원·한국전력·KENTECH를 각각 직접 대조했으나 촬영 연도는 미확인. 원본 영상·사진은 웹 배포본에 포함하지 않음.
- 이동 검사 68개 통과: 높은 공원 시작점, 계단형 산책로, 전망실 유리 경계, 두 기관의 정문 왕복, 기존 장소·선박 동선. 브라우저에서 조감 푯말→공원→전망실 전환도 확인.

생성: `prepare_bitgaram.py`로 OSM 정리 후 `build_bitgaram.py`, `build_bitgaram_institutions.py`, `render_bitgaram_hub.py` 실행. `--replace-generated`는 이번 생성본만 갱신할 때 사용하며 사용자 수동 편집본에는 사용하지 않음.
