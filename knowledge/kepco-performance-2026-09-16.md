# 한전 산책 렌더링 최적화

- 원인 후보 확인: 모델의 투명 유리 318개, 월드 조명 130개, 충돌체 668개. 기존 불투명 모델 병합은 이미 활성화되어 있다.
- 한전 구역에만 주변 조명 풀 최대 8개 적용. 150ms 간격으로 카메라 주변 조명을 선택하고 동일한 Light 객체를 재사용한다. 조명 원본 좌표와 건물의 형상은 변경하지 않았다. 먼 곳의 직접 조명은 생략된다.
- 고정된 태양 그림자는 재사용하며, 전체 보기/걷기 변경으로 지붕 표시가 바뀔 때 갱신한다.
- 픽셀 비율 상한 1.75→1.25. 고밀도 화면의 렌더 픽셀 수 약49% 감소. 대신 미세한 선의 선명도가 약간 줄 수 있다.
- 정적 GLB의 로컬 행렬 재계산 중지. Blender 모델과 충돌 자료는 그대로 보존한다.
- 실기기 FPS 수치는 측정하지 않았으며, 개선 폭을 특정 배수로 보장하지 않는다.
- 검증: 조명 풀 이동/범위 이탈 테스트, TypeScript, 빌드 및 기존 월드 검사.

이전 파노라마 검사 실패는 Blender가 순수 발광 노드를 KHR_materials_unlit 대신 검은 바탕+발광 텍스처로 내보낸 차이였다. 해당 출력도 검사하고, 표시 시 MeshBasicMaterial로 변환해 외부 조명 영향을 없앤다.
