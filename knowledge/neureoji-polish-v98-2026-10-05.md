# 느러지 전망대 표고 재검토 및 폴리싱 v98

조회·검증일: 2026-10-05. 기존 v97b Blender 수정본을 열어 편집했고 새 `outputs/neureoji-polish-v98/neureoji-polish-v98.blend`로 저장했다. 사용자 수정본은 덮어쓰지 않았다.

## 고도 판단

| 항목 | 높이 | 판단 |
|---|---:|---|
| GLO-30 전망대 좌표 표면 | 45.76368m | 원래 DSM 표면, 수관·시설 영향 가능 |
| AWS Terrarium 동일 좌표 | 45.66812m | 이번 재조회 값, GLO-30과 약 0.096m 차이 |
| 모델 지면 | 45.76368m | 기존 해석 유지, 지면 실측으로 확정하지 않음 |
| 모델 상층 데크 | 57.76368m | 지면에서 12m, 보행 높이 유지 |
| 모델 구조 전체 높이 | 15.35m | 데크 높이와 구분, 사진 참고 치수 |

기준 좌표는 34.9159348 / 126.5419381(OSM 노드 6572786690). 동일 지형 제품을 반복 조회해 같다는 사실과 제품 간 일치는 현장 측량 검증을 의미하지 않는다. 전망대 부지의 지면 표고를 확정할 신규 실측 자료를 확보하지 못했으므로 다시 임의로 높이지 않았다. Terrarium은 여러 DEM을 조합한 제품이고 실제 원자료 해상도와 타일 픽셀 간격은 구분해야 한다. 10개 주변 표본·타일 해시는 `sources/neureoji-polish-v98/elevation-check.json`에 보관했다.

[2018년 방문 사진 및 설명](https://live112.tistory.com/5000)은 기존 철골 전망대의 높이를 약 15m로 설명한다. 이는 해발 높이나 상층 데크 높이를 뜻하지 않는다. [2024년 방문 사진](https://forme13.tistory.com/3621)은 숲과 수국길, 강변과 전망대의 높이 관계를 참고하는 자료다. 사진에서 정확한 지면 표고를 계산하지 않았다. 예정된 신축 전망대의 높이를 현재 모델에 적용하지 않았다.

강 수면은 모델의 표시 평면이며 관측 수위와 수직 기준을 확인한 값이 아니다. 따라서 ‘모델 지면 y=45.76m’를 현장 강 수면 대비 정확한 고저차로 단정하지 않는다. 이 점을 `public/neureoji-world.json`의 elevationAudit에 명시했다. 원래 v92 조사 문서의 8m 수관 차감은 과거 기록이며 현재 적용값은 v96 이후의 차감 0m다.

## 폴리싱

원경의 교차 평면 수관 38,228개를 폭 0.72배로 조정해 과도한 가로 겹침을 줄였다. 윤곽에 검은 테두리가 두드러지던 텍스처를 자체 제작한 작은 잎의 색 변화·불규칙 윤곽으로 교체했다. 기존 4개 수관 배치와 재질을 재사용해 메시 수를 늘리지 않았다. 참고 사진은 배포 텍스처로 사용하지 않았다.

반경 480m 이내의 수관 1,837개를 Blender의 표시 지형에 조회해 수직 정렬했다. 1,387개는 20cm 이상 조정됐고, 최대 조정 범위는 -10.74~+9.14m다. 이는 기존 추정 식재와 표시 지형의 차이를 정리한 것으로 실제 수종·나무 높이·수목 위치의 실측이 아니다. 근거리 가지와 입체 수관은 v97 모델을 유지했다. 먼 숲은 성능을 위한 평면 표현이 남는다.

지형, 전망대 구조물, 강, 보행 바닥 41개 메시의 POSITION 스트림이 v97 배포 GLB와 정확히 같다. 충돌 solids 역시 동일하다. 새 Blender 출처와 고도 검토 기록을 장소 메타데이터에 갱신했고 앱의 모델 캐시 버전을 변경했다.

## 검증

- 공통 이동 74개, 느러지·수관·표고 관련 15개 테스트 통과(총 89개). 전체 저장소의 모든 테스트를 실행했다는 뜻은 아니다.
- TypeScript 및 production 정적 빌드 성공. 기존 큰 번들 크기 경고는 남는다.
- 실제 브라우저에서 상층과 숲길 도착점을 확인했고 JavaScript 오류가 보고되지 않았다.
- gzip 해제 결과와 원본 GLB, 정적 빌드의 gzip이 정확히 동일하다. 다운로드는 16,769,988바이트로 16MiB 한도 이내지만 여유가 작다.
- 원본 v97b 해시 유지 및 새 파일 별도 저장 확인. `sources/neureoji-polish-v98/verification.json`에 보호 메시·배포 검증 기록을 보관했다.
- OSM/ODbL 및 기존 Copernicus 출처 표기를 유지했다. Blender·조사 사진·임시 파일·라이브러리는 배포에 포함하지 않았다. 커밋·푸시·공개 배포는 하지 않았다.
