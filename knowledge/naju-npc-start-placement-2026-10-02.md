## 구현과 자료 구분

- 캐릭터와 안내 배치 위치는 사용자 요청에 따른 창작 요소다. 실제 현장 시설이나 실제 사람 위치가 아니다.
- `public/npc-placements.json`에 모델 4종, 배치 7곳, 바닥 높이, 정면 방향, 몸통 충돌 반경을 저장한다. 시작점에서 약 4.71m 앞, 시야 중앙에서 약 17.3도 옆이며 출발점 방향을 바라본다.
- 기존 Blender 채색 초안 v4를 그대로 `public/models/npc/`로 복사한다. 원본 GLB·BLEND 및 지도 GLB를 수정하지 않는다. 원본과 배포 파일 바이트 일치 검사를 수행한다.
- 각 맵은 해당 캐릭터 GLB 하나만 불러온다. 기존 지도 메시 합치기에서 분리하며, 고정 자세를 유지하므로 뼈대 애니메이션이나 프레임별 NPC 연산이 없다.
- NPC JSON의 작은 몸통 충돌 영역을 런타임 World에 반영한다. 이동과 지도 순간 이동이 같은 충돌 정보를 사용한다. 기존 출발점·문·길·세계 JSON 좌표는 보존한다.
- 같은 지역의 실내 장면에 중복 추가하지 않는다. 전망실 내부 비우기 요청을 유지하며, 대표 캐릭터가 지정되지 않은 수목원·드들강에는 임의 배정하지 않는다. 빛가람 전체 안내 지도는 공원 산책 입구로 연결한다.
- 현재 캐릭터는 정지 자세의 채색 초안이다. 조형·손 모양 보완, 리깅, 인사 동작, 대화 기능은 이번 배치 작업의 완료 항목이 아니다.

## 검증

- 지역 배정 7곳, 초기 시야·방향·접지·기존 지형 가림 없음·출발 경로·문 간섭·NPC 충돌·원본 보존 테스트 9개 추가.
- `node --experimental-strip-types --test tests/npc-placement.test.mjs tests/world.test.mjs`: 82개 통과.
- TypeScript 검사, 생산 빌드 통과.
- 로컬 생산 빌드 웹 화면을 확인하고 `outputs/npc-placement-20261002/`에 시작 화면을 기록한다.
- 배포 성공 상태는 배포 이후 별도 기록으로 확인한다.

## 재현

`node --experimental-strip-types scripts/place_naju_npcs.mjs`는 기존 지도·Blender GLB를 읽어 시작점 근처의 접근 가능한 위치를 찾는다. 캐릭터 배포 복사본과 배치 JSON만 갱신한다. 원본 Blender 파일을 생성 스크립트로 덮어쓰지 않는다.
