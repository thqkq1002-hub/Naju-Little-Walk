# 지역 안내 캐릭터 리깅과 손·모자 보정

2026-10-02. 사용자가 네 캐릭터의 형태 생성·리깅·서 있는 자세와 대화 중 자연스러운 포즈 변경을 요청했다. 검토 이미지에서 배돌이 손과 모자, 버들낭자의 손·치마 변형을 지적해 보정했다. 도시 지형과 사용자 수정 Blender 원본은 변경하지 않았다.

## 생성과 비용

- 기존 배돌이 Meshy 7.1 원본은 보존했다. 나머지 버들낭자·홍돌이·선생님은 각각 35크레딧, 합계 105크레딧으로 4K 형태·4K 색상·PBR 원본을 생성했다. 당시 잔액 1,065 → 960.
- 손을 모자에서 떨어뜨린 배돌이 참조를 내장 imagegen 도구로 새로 만들었다. 원래 노란 배 얼굴·주황 밀짚모자·파란 목수건·크림색 몸을 유지했다. 기본 손에 든 배는 빼고 양손이 드러나는 낮은 A 자세로 구성했다.
- 이 참조로 Meshy 7.1 재생성 1건을 수행했다. 작업 `01a0fc2e-5951-723b-a4af-93110c47bae5`, 성공 100%. 실제 잔액 **960 → 925**, 차감 **35크레딧**. 새 원본은 `assets/npc/meshy71-baedoli-clean-20261002/baedoli-meshy71-original.glb`다.
- 리깅·동작 제작·수정은 로컬 Blender에서 수행했다. 이 작업에 Meshy 자동 리깅 API 크레딧은 사용하지 않았다. 참고: [Meshy 공식 요금](https://docs.meshy.ai/en/api/pricing), [Image-to-3D API](https://docs.meshy.ai/en/api/image-to-3d).
- 비밀 키는 명령 프로세스 환경에서만 사용했다. 소스·문서·Git에 저장하지 않았다. 서명된 다운로드 응답은 Git에서 제외된 `outputs` 안에만 보관한다.

## 원인과 제작 방식

배돌이의 기존 엄지 포즈는 손과 모자가 매우 가까웠다. 단일 메시의 리깅 영역이 겹쳐 모자 일부에 손 뼈의 영향이 생겼다. 새 참조와 모델에서는 손·팔·모자를 공간적으로 분리했다. 모자와 얼굴은 머리 뼈를 따르고 손가락은 손 뼈에 붙여 형태를 유지한다.

버들낭자는 실제 팔 길이와 기존 리그의 팔 길이가 달랐고, 낮게 내려온 손·파란 소매 장식이 치마 영역으로 분류됐다. 실제 어깨·팔꿈치·손목에 뼈를 다시 맞춘 v6을 만들었다. 치마와 손을 분리하고 소매 경계의 움직임 영향을 부드럽게 연결했다. 생성 원본을 다시 결제하지 않고 리깅을 수정했다.

각 모델에 18개 뼈(홍돌이는 꼬리 포함 19개)와 `Idle`, `Greeting`, `Explain`, `Nod`, `Listen` 동작을 넣었다. 발 위치를 움직이지 않고 동작 전환을 부드럽게 이어 붙인다. 원본·편집 Blender에는 고해상도 텍스처를 보존하고 웹에는 2K WebP 텍스처를 내장한 별도 GLB를 내보낸다. 배돌이는 약 60,000삼각형, 버들낭자·선생님 55,000, 홍돌이 45,000이다. 맵마다 해당 지역 캐릭터 한 개를 읽는다.

## 앱 동작과 범위

기존 사용자 지정 7개 시작 위치를 유지했다. 배돌이는 전망대 공원·한전 본사·KENTECH, 버들낭자는 금성관·복암리 고분, 홍돌이는 영산포, 선생님은 다시초등학교다. 비어 있는 전망실과 미지정 맵에는 새 캐릭터를 넣지 않았다.

6m 안에서 ‘캐릭터와 이야기’를 눌러 인사·안내·고개 끄덕임 등을 요청할 수 있다. 현재 대답은 해당 맵의 기존 소개와 한국어 동작 명령에 대한 로컬 응답이다. 외부 생성형 AI 대화, 마이크 대화, 얼굴 표정 리깅·입술 동기화는 구현하지 않았다. 한국어 브라우저 음성이 있으면 사용자의 요청을 받아 읽고, 없으면 글로 안내한다.

캐릭터는 도시 정적 배치와 분리돼 움직인다. 정적 그림자 캐시를 오염시키지 않도록 바닥 접촉 그림자를 별도로 사용한다. 멀리 있거나 전체 보기·백그라운드·회전 안내 상태에서는 동작 계산을 멈춘다. 움직임 감소 설정도 따른다.

## 검증

- 실제 Blender 파일에서 기본 자세·인사·설명을 렌더해 손·모자·치마를 확인한다.
- 배포 GLB와 편집용 내보내기가 정확히 일치하는지, 텍스처 내장·뼈·다섯 동작·5MB 이하 크기를 검사한다.
- 실제 GLB의 변형된 정점을 검사해 발 접지와 짧은 표면 연결이 찢어지듯 늘어나는 문제를 확인한다. 단순히 뼈가 존재하는 검사만으로 외형 품질을 통과 처리하지 않는다.
- 기존 시작 위치·문·통로·시야와 73개 이동 검사를 유지한다.
- 로컬 브라우저에서 대화 버튼·인사·끄덕임·닫기 후 보행 복귀를 확인한다.

웹 모델과 보정된 미리보기는 창작 캐릭터다. 단일 정면 이미지에 없는 후면은 Meshy의 추정 형태이며 공식 후면 자료와 대조한 결과가 아니다.

- 캐릭터·배치·실제 표면 변형 검사 **21/21 통과**. 처음 보정 두 모델에 적용했던 표면 검사를 네 모델 모두로 확장했다.
