# 드들강 솔밭·강 구간 축소와 미사용 파일 정리 v81

## 요청과 지도 범위

사용자가 큰 산 배경과 주변 구역을 빼고 **드들강 솔밭유원지와 바로 옆을 흐르는 강만 남기도록** 요청했다. 이번 변경은 지도의 표시 범위를 편집한 것이다. 새 현장 측량이나 시설 고도화로 설명하지 않는다.

- 보존: 기존 소나무 280그루의 가까운/먼 모델 560개, 나무 정점·면·변환, 솔밭 윤곽, OSM 숲길 1306096510·1306096511 중 솔밭 안 구간, 강변 산책로, 노래비·벤치·솔밭 쉼터, 기존 도착 지점. 솔밭 끝을 지나던 길의 연장 부분은 제거했다.
- 제거: 추정 산과 숲 배경, 농경지·작물 줄, 교량, 외부 도로·주차장, 솔밭 밖 북쪽 화장실.
- 강: 기존 강 윤곽을 솔밭 인접 구간으로 잘랐다. 표시 경계는 `[-235,88,-198,290]`이고, 원래 지리 좌표는 바꾸지 않았다.
- 바닥: 큰 사각 지면을 빼고 기존 솔밭 윤곽을 따라 작은 여유 영역을 추가했다. 숲길 연결부에는 수치 오차로 발이 막히지 않도록 작은 바닥 연결 여유를 뒀다.
- 이동: `public/deudeulgang-world.json`의 강 충돌과 바닥·경계를 함께 갱신했다. 바닥이 없는 곳과 강으로 걸어 나가거나 미니맵으로 이동할 수 없다.
- 첫 화면: 산 배경 대신 솔밭과 강을 중심으로 보여 주도록 카메라를 조정했다. 나주 전체 지도와 다른 장소 선택은 유지한다.

## 파일 정리 기준과 결과

앱 진입점·개발 설정·검사 파일의 import 연결과 실제 NPC manifest를 확인했다. 사용 여부가 불분명한 작업물은 삭제 대상으로 분류하지 않았다.

- 현재 앱에서 불러오지 않는 기본 UI 60개, 보조 hook·utils·설정 3개를 정리했다.
- 쓰이지 않는 과거 전망 영상 UI 1개와 미디어 4개, 현재 v6으로 교체된 공개 NPC v4·v5 파일 8개를 정리했다.
- 총 76개 파일을 활성 소스·공개 폴더에서 제거하고 `outputs/cleanup-v81/removed/`에 복구용으로 옮겼다. 이 폴더는 Git·배포에서 제외된다. 원본 영상과 예전 캐릭터도 이곳에 보존된다.
- `.next`, `.vinext`, `.wrangler`, TypeScript 캐시를 삭제했다. 검증·빌드에서 필요한 캐시는 다시 만들어질 수 있다.
- 다른 맵, Blender 편집 원본·수정본, 사진 연구 자료, 제작 스크립트와 아직 진행 중인 사용자 작업물은 유지했다. 원본 GLB는 압축 검증·모델 검사에 쓰이므로 유지하고 운영 빌드에서는 중복 복사본을 제외한다.
- 활성 폴더에서 빠진 파일·캐시는 총 약 41.9MB다. 복구용 보관 파일은 디스크에 남으므로 이 숫자를 전체 디스크 확보량으로 설명하지 않는다.

[정리 목록](sources/workspace-cleanup-v81.json). 감사 도구: `scripts/audit_dead_files_v81.mjs`, 정리 도구: `scripts/cleanup_dead_files_v81.ps1`.
