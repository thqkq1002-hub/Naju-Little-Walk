# 느러지 전망대 정밀 보강 계획 v93

## 대조 결과

기존 v92e는 실제 OSM 강 윤곽과 계단 보행이 연결되어 있으나, 2024년 방문 사진 06·08과 실제 배포 화면을 대조하면 원경 숲의 간격·둥근 덩어리가 두드러지고 들판 구획·마을·산 능선이 약하다. 가까운 활엽수 잎도 과도하게 크다. 정상 화면의 큰 빈 지붕 면과 기둥이 중앙 조망을 차지한다.

## 보강 순서

1. **조망 지형**: 기존 OSM 물 경계를 보존한다. 공개 위성 참고 영상에서 보이는 농경지·숲을 자체 벡터로 구분하고, 30m DSM을 바탕으로 농경지의 낮은 지면·강변 수림·외곽 산 능선을 보강한다. 개별 경작 경계는 영상 참고 추정으로 명시한다. 실제 사진·위성 영상을 배포용 배경으로 붙이지 않는다.
2. **시설과 식재**: 기존 저장본에서 새 Blender 수정본을 만든다. 세 개의 외부 계단, 직사각형 참, 원형 정상층·지붕을 유지하고 목재 난간, 철골 연결부, 발판, 지붕 하부, 벤치, 수국과 소나무를 보강한다. 사진에 없는 중간 원형 층을 임의로 추가하지 않는다.
3. **눈높이와 작동 확인**: 정상층 내 실제 보행 가능한 위치 중 중앙 기둥에 덜 가려지는 위치를 선정한다. 지붕과 난간을 삭제하거나 사람 눈높이를 높여 조망을 과장하지 않는다. 계단 왕복·난간·바닥 높이를 내보낸 GLB와 대조하고, Blender 렌더와 실제 브라우저 화면을 반복 검토한다.
4. **앱 반영**: 업데이트된 GLB와 `public/neureoji-world.json`을 함께 반영한다. 모델 용량·메시 수, 이동 테스트, TypeScript와 빌드 확인 후 기존 GitHub/Vercel 배포로 반영한다.
