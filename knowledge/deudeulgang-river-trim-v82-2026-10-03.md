# 드들강 강 표시 범위 축소 v82

사용자가 표시한 빨간 선 바깥의 넓은 물 면을 없애고 솔밭 바로 옆 강 구간만 남겼습니다. v81 편집본을 읽어 Blender에서 강의 먼 쪽을 잘랐으며, 새 편집본은 `outputs/deudeulgang-v82/deudeulgang-river-trim-v82.blend`입니다. 원본 v81 파일을 덮어쓰지 않습니다.

## 변경 범위

- 세계 좌표 x=-125m를 새 강 표시 끝으로 설정합니다. 기존 솔밭 쪽 물가의 굴곡은 유지합니다.
- 강 메시와 `mapped_river_water`, `river_no_walking`의 윤곽을 함께 줄입니다. 이동 가능한 솔밭, 기존 산책로와 도착점은 유지합니다.
- 강 이외 모든 메시의 정점·면·위치·재질 해시가 동일한지 검사합니다. 소나무 280쌍과 시설·산책로를 보존합니다.
- 전체 보기 중심을 솔밭 쪽으로 옮기고 거리를 줄여 화면에 맞춥니다.

## 실제 자료와 표시용 편집 구분

기존 OSM 기반 강변·산책로와 솔밭 자료를 유지합니다. 이번 잘라낸 경계는 사용자 요청에 따른 화면 표시 범위이며, 실제 강폭을 재측량하거나 변경한 자료가 아닙니다. 기존 출처와 ODbL 표기를 유지합니다.

정확한 면적 감소, 보호 객체 수, 파일 해시는 [생성 검사 기록](sources/deudeulgang/river-trim-v82.json)에 저장합니다. 보행·지도 경계 테스트, GLB·gzip 일치 검사, TypeScript와 배포 빌드, 브라우저 전체 보기로 확인합니다.
